## 3. 기능별 상세 설계

### 3.1 API 자동 탐색

#### 3.1.1 DART 캘린더 연동

DART OpenAPI를 통해 국내 상장사 공시 중 배당·실적·청약 관련 이벤트를 수집한다.

**서버 엔드포인트 추가 (`server/calendarHandler.js` 신규):**

```
GET /api/dart/calendar/dividend?bgn_de=20260501&end_de=20260630
  → DART /api/alotMatter.json (bbmTp 배당 필터링) 후 캘린더 이벤트 형식 반환

GET /api/dart/calendar/earnings?bgn_de=20260501&end_de=20260630
  → DART /api/list.json (pblntf_ty I, 공시 검색어 실적) 파싱
```

**요청 흐름:**
```
클라이언트 → /api/dart/calendar/dividend
  → server: req.headers['x-dart-api-key'] 추출
  → DART OpenAPI 호출
  → 공시 목록 파싱 → CalendarEvent 형식으로 변환
  → 클라이언트 반환
```

**변환 결과 형식:**
```js
{
  title: '삼성전자 배당기준일',
  date: '2026-06-30',
  category: 'dividend',
  ticker: '005930',
  market: 'KRX',
  impact: 'medium',
  source: 'dart',
  memo: '배당 공시',
}
```

#### 3.1.2 Finnhub 연동 (미국 실적·IPO)

Finnhub 무료 플랜(60req/min)으로 미국 실적·IPO 일정을 수집한다.

**Finnhub API 키 관리 (신규):**
- `aiCredentialStore.js`에 `finnhubApiKey` 필드 추가
- `src/components/settings/FinnhubKeyPanel.jsx` 생성
- `Settings.jsx`에 FinnhubKeyPanel 마운트

**서버 엔드포인트 추가:**
```
GET /api/finnhub/calendar/earnings?from=2026-06-01&to=2026-06-30
  → Finnhub /calendar/earnings 프록시 (x-finnhub-token 헤더 사용)
  → EPS estimate, 발표 시간(BMO/AMC) 포함 반환

GET /api/finnhub/calendar/ipo?from=2026-06-01&to=2026-06-30
  → Finnhub /calendar/ipo 프록시
```

**변환 결과 형식:**
```js
{
  title: 'Apple 2Q 실적 발표 (BMO)',
  date: '2026-07-24',
  category: 'earnings',
  ticker: 'AAPL',
  market: 'NASDAQ',
  impact: 'high',
  source: 'finnhub',
  memo: 'EPS 예상: $1.42',
}
```

#### 3.1.3 자동 탐색 UI

**MarketCalendar.jsx 상단 툴바에 자동 탐색 버튼 추가:**

```
[자동 탐색 ▾]  → 드롭다운: [이번 달] [다음 달] [향후 3개월]
```

### 3.2 매매일지 연계

**EventDetailModal.jsx에 '일지 작성' 버튼 추가:**

조건: 이벤트에 `ticker`가 있을 때만 버튼 표시.

```jsx
{event.ticker && (
  <button onClick={handleOpenJournal}>
    일지 작성
  </button>
)}
```

**동작 흐름:**
1. '일지 작성' 클릭
2. `navigate('/journal', { state: { prefill: { ticker, date, memo: event.title } } })`
3. Journal 페이지에서 `location.state?.prefill` 감지 → JournalEntryForm에 날짜·종목 사전 입력
4. Journal 페이지가 이미 `location.state`를 사용하는지 확인 후 충돌 없이 적용

### 3.4 브라우저 알림

Web Notifications API 기반 (ServiceWorker 없는 클라이언트 사이드 스케줄링).

- 페이지 로드 시 권한 확인 (`Notification.permission`)
- 캘린더 페이지 진입 시 당일 + 익일 이벤트 체크 후 알림 스케줄
- `impact: 'high'` 이벤트만 기본 알림 (설정에서 조정 가능)

**알림 설정 (`settingsStore.js` 추가):**
```js
calendarNotification: {
  enabled: false,
  timing: 'sameDay',          // 'sameDay' | 'dayBefore'
  impactFilter: 'high',       // 'all' | 'high' | 'highAndMedium'
}
```

**`src/utils/calendarNotifier.js` (신규):**
- `requestPermission()` — 알림 권한 요청
- `scheduleNotifications(events, settings)` — 이벤트 배열 → setTimeout 스케줄
- `cancelAll()` — 예약된 알림 취소

**Settings.jsx — 알림 설정 섹션 추가:**
- 알림 켜기/끄기 토글
- 알림 시점 선택 (당일 아침 09:00 / 전날 밤 21:00)
- 임팩트 등급 필터 선택

### 9.1 자동 탐색 기본값 변경 (FetchPreviewModal)

**현재 동작:** 모달 오픈 시 중복이 아닌 항목이 모두 자동 선택된 상태로 표시된다.

**변경 동작:** 모든 항목을 선택 해제 상태로 초기화한다. 사용자가 원하는 항목만 직접 선택 후 저장한다.

**수정 파일:** `src/components/calendar/FetchPreviewModal.jsx`

```js
// 변경 전 — 비중복 항목 자동 선택
useEffect(() => {
  if (!open) return
  const initial = new Set()
  results.forEach((ev, i) => { if (!isDuplicate) initial.add(i) })
  setChecked(initial)
}, [open, results, existingMap])

// 변경 후 — 전체 해제
useEffect(() => {
  if (!open) return
  setChecked(new Set())
}, [open, results, existingMap])
```

### 9.2 +N more 팝업 스크롤 + 체크박스 + 일괄 삭제 (DayEventsModal)

FullCalendar의 "+N more" 링크를 클릭하면 커스텀 팝업을 열어 날짜별 이벤트 목록을 스크롤, 선택, 삭제할 수 있게 한다.

**신규 컴포넌트:** `src/components/calendar/DayEventsModal.jsx`

```
props:
  open: boolean
  date: string            — "2026-07-15" 형식
  events: CalendarEvent[] — 해당 날짜의 이벤트 목록 (중요도 정렬 완료 상태로 전달)
  onClose: () => void
  onDelete: (ids: number[]) => void
```

**UI 구성:**

```
[날짜 제목]                       [×]
─────────────────────────────────
☐  [전체 선택]         삭제 (N건)
─────────────────────────────────
☐  ★★★ 삼성전자 실적        DART
☐  ★★  배당락일              수동
☐  ★   AAPL 실적           Finnhub
   ... (스크롤)
─────────────────────────────────
                          [닫기]
```

- 이벤트 영역 최대 높이 `max-h-80` + `overflow-y-auto` 스크롤 지원
- 전체 선택/해제 체크박스 (indeterminate 상태 포함)
- 개별 체크박스로 이벤트 선택
- [삭제 (N건)] 버튼 — 선택 항목이 없으면 비활성화
- 삭제 확인 없이 즉시 실행 (`calendarStore.deleteEvent` 반복 호출)

**CalendarMonthView.jsx 변경 — moreLinkClick 인터셉트:**

```jsx
moreLinkClick={(info) => {
  info.jsEvent.preventDefault()
  const dateStr = info.date.toISOString().slice(0, 10)
  onMoreLinkClick(dateStr)
  return { action: 'none' }
}}
```

`onMoreLinkClick` prop을 새로 추가한다. MarketCalendar에서 날짜 문자열을 받아 DayEventsModal을 열 수 있다.

**MarketCalendar.jsx 변경:**

```js
// DayEventsModal 상태 추가
const [dayEventsModal, setDayEventsModal] = useState({ open: false, date: null })

// CalendarMonthView에 콜백 전달
onMoreLinkClick={(date) => setDayEventsModal({ open: true, date })}

// DayEventsModal 마운트
<DayEventsModal
  open={dayEventsModal.open}
  date={dayEventsModal.date}
  events={displayedEvents.filter(ev => ev.date === dayEventsModal.date)}
  onClose={() => setDayEventsModal({ open: false, date: null })}
  onDelete={(ids) => ids.forEach(id => deleteEvent(id))}
/>
```

### 9.3 중요도 정렬

모든 뷰에서 이벤트를 중요도 높은 순(high → medium → low → undefined)으로 표시한다.

**정렬 상수:**

```js
const IMPACT_ORDER = { high: 1, medium: 2, low: 3 }
const impactSort = (a, b) =>
  (IMPACT_ORDER[a.impact] ?? 4) - (IMPACT_ORDER[b.impact] ?? 4)
```

**MarketCalendar.jsx — displayedEvents useMemo에 정렬 추가:**

```js
return filtered.slice().sort(impactSort)
```

FullCalendar의 `dayMaxEvents={3}`가 상위 3개를 노출하므로, 정렬된 배열의 앞 3개가 자연스럽게 높은 중요도 이벤트가 된다.

**CalendarWeekView.jsx — eventsByDate Map 생성 후 각 배열 정렬:**

```js
eventsByDate.forEach((arr, date) => {
```
