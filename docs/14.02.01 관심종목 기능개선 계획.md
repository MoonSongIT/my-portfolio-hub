# 14.02.01 관심종목 기능개선 계획

## 작성일
2026-06-05

## 배경

관심종목 목표가 설정 패널(TargetPriceBar)에서 다음 두 가지 문제가 보고됨.

1. 보유 중인 종목의 평균매입가를 수동으로 직접 입력해야 함 — 포트폴리오에 이미 있는 값을 다시 치는 불편함
2. 설정 페이지에서 저장한 기본 %(목표가, 손절가)가 패널을 열어도 % 입력란에 반영되지 않음

---

## 현황 분석

### A. % 입력란 초기화 버그

**파일:** `src/components/watchlist/TargetPriceBar.jsx` L50-57

```javascript
const [draft, setDraft] = useState({
  entryPrice:  stock.entryPrice  != null ? String(stock.entryPrice)  : '',
  targetPrice: stock.targetPrice != null ? String(stock.targetPrice) : '',
  targetPct:   '',    // ← 항상 빈 문자열로 초기화
  stopLoss:    stock.stopLoss    != null ? String(stock.stopLoss)    : '',
  stopLossPct: '',    // ← 항상 빈 문자열로 초기화
  trailingDropPct: ...
})
```

`entryPrice`와 `targetPrice`가 저장되어 있어도 패널을 열면 `%` 란이 항상 비어있음.
`pctFromPrices()` 함수가 이미 구현되어 있으므로 초기화 시 역산만 추가하면 됨.

### B. 설정 기본값 placeholder 미표시

`targetPct` placeholder가 하드코딩 `"+20"`. 설정에서 바꿔도 placeholder가 그대로임.
`stopLossPct` placeholder도 `"-10"` 하드코딩.

### C. 보유 종목 매입가 가져오기 버튼 없음

`journalStore.computeAllHoldings()` → ticker 매칭 → `avgPrice` 조회 경로가 이미 존재하지만 TargetPriceBar에서 활용하지 않음. 버튼 한 개 추가로 해결 가능.

### D. 자동 계산 로직은 이미 구현됨

`handleEntryChange()`가 매입가 입력 시 목표가/손절가를 자동 계산하는 로직을 갖추고 있음. 버튼 클릭 시 이 함수에 `avgPrice`를 넘기기만 하면 됨.

---

## 개선 범위

### 개선 1 — % 초기값 역산 (버그 수정)

**대상 파일:** `src/components/watchlist/TargetPriceBar.jsx`

패널 open 시 초기 draft 계산을 다음과 같이 수정.

```
초기화 조건:
  entryPrice + targetPrice 둘 다 있음  → targetPct = pctFromPrices(targetPrice, entryPrice)
  entryPrice + stopLoss 둘 다 있음     → stopLossPct = pctFromPrices(stopLoss, entryPrice)
  그 외                                 → '' (기존 동작)
```

### 개선 2 — 설정 기본값을 placeholder로 반영

`targetPct` 입력란의 placeholder를 `watchlistDefaults.targetPct` 값으로 동적으로 표시.
`stopLossPct` 입력란도 동일하게 `-watchlistDefaults.stopLossPct` 표시.

### 개선 3 — 보유 종목 평균매입가 가져오기 버튼

**위치:** 매입가 입력란 오른쪽 (인라인 아이콘 버튼)

**표시 조건:** `journalStore.computeAllHoldings()`에서 같은 ticker를 가진 보유 종목이 있을 때만 표시

**동작 흐름:**
1. `computeAllHoldings()`에서 해당 ticker의 `avgPrice` 조회
2. `handleEntryChange(String(avgPrice))` 호출 → 기존 자동 계산 로직이 목표가/손절가를 자동 제시
3. 아이콘: lucide-react `RefreshCw` 또는 `Download` (기존 패키지 내 아이콘)
4. 툴팁: "포트폴리오 평균매입가 {avgPrice}원 가져오기"

### 개선 4 — 자동 계산 후 저장 흐름 확인

기존 `handleSave()` → `updateWatchlistTargets()` → IDB 저장 흐름은 정상 동작 확인됨. 추가 수정 불필요.

## 구현 계획

### Step 1 — % 초기값 역산 + placeholder 동적화 (개선 1·2)

**변경 파일:** `src/components/watchlist/TargetPriceBar.jsx`

```
- useState 초기값에서 pctFromPrices() 호출하여 targetPct, stopLossPct 역산
- targetPct 입력란 placeholder: `+${watchlistDefaults.targetPct}`
- stopLossPct 입력란 placeholder: `-${watchlistDefaults.stopLossPct}`
```

검증: 목표가+매입가 저장된 종목 카드를 열면 % 란에 역산 값이 표시되는지 확인

### Step 2 — 보유 종목 매입가 가져오기 버튼 추가 (개선 3)

**변경 파일:** `src/components/watchlist/TargetPriceBar.jsx`

```
- useJournalStore import 추가
- useMemo로 holdings avgPrice 조회 (stock.ticker 기준)
- avgPrice 있을 때만 매입가 입력란 오른쪽에 아이콘 버튼 렌더링
- 클릭 시 handleEntryChange(String(avgPrice)) 호출
```

검증: 포트폴리오 보유 종목 관심종목 카드에서 버튼 표시 확인, 클릭 시 목표가/손절가 자동 계산 확인
