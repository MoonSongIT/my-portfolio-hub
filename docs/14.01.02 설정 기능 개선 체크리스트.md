## 수작업 검증 (배포 후)

아래 항목을 앱을 직접 열어서 확인하세요.

**A — API 키 통합 패널**
1. 사이드바 → ⚙️ 설정
2. "AI 및 API 키" 섹션 확인 — 3개 서비스(Anthropic AI / DART / Finnhub)가 한 카드에 목록으로 표시됨
3. Anthropic AI 행 → "설정" 버튼 → 입력 폼 펼쳐짐 / 취소 버튼으로 닫힘
4. 키 입력 후 저장 → 상태 배지가 "미검증"으로 변경
5. "검증" 버튼 클릭 → 성공 toast
6. "삭제" 버튼 → 확인 모달 → 삭제 후 "미설정"으로 변경
7. DART / Finnhub도 저장·삭제 동작 확인

**B — 연결 & 동기화 통합**
1. 비로그인 상태: "연결 & 동기화" 섹션에 "서버 계정 연결" + 로그인 버튼만 표시 (동기화 설정 없음)
2. 로그인 후: 연결됨 + 동기화 설정(토글, 업로드/다운로드) 표시

**C — 데이터 관리 통합**
1. "데이터 관리" 섹션 하나에 백업&복원 → HTS 가져오기 → 저장소 현황 → 전체 초기화 → 앱 정보 순서로 표시

**D — 종목 DB 단순화**
1. "종목 DB 관리" 섹션: "데이터 출처" 선택 버튼 없음
2. "서버 종목 데이터" 카드 + "서버에서 받기" 버튼만 표시

**E — 버전 수정**
1. "데이터 관리" 섹션 하단 앱 정보 → 버전: `0.1.0`

**G — 알림 conditional hide**
1. 알림 섹션 → "알림 꺼짐" 상태 → "알림 시점" / "중요도 필터" 행이 보이지 않음
2. "알림 켜짐" 상태 → 두 옵션 표시됨
