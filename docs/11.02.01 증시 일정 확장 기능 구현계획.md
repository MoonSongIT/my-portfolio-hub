## 3. 기능별 상세 설계

### 3.1 API 자동 탐색

#### 3.1.1 DART 캘린더 연동

DART OpenAPI를 통해 국내 상장사 공시 중 배당·실적·청약 관련 이벤트를 수집한다.

**서버 엔드포인트 추가 (`server/calendarHandler.js` 신규):**

```
GET /api/dart/calendar/dividend?bgn_de=20260501&end_de=20260630
  → DART /api/alotMatter.json (bbmTp 배당 필터링) 후 캘린더 이벤트 형식 반환

GET /api/dart/calendar/earnings?bgn_de=20260501&end_de=20260630
  → DART /api/list.json (pblntf_ty I, 공시 검색어 실적) 파싱
```

**요청 흐름:**
```
클라이언트 → /api/dart/calendar/dividend
  → server: req.headers['x-dart-api-key'] 추출
  → DART OpenAPI 호출
  → 공시 목록 파싱 → CalendarEvent 형식으로 변환
  → 클라이언트 반환
```

**변환 결과 형식:**
```js
{
  title: '삼성전자 배당기준일',
  date: '2026-06-30',
  category: 'dividend',
  ticker: '005930',
  market: 'KRX',
  impact: 'medium',
  source: 'dart',
  memo: '배당 공시',
}
```

#### 3.1.2 Finnhub 연동 (미국 실적·IPO)

Finnhub 무료 플랜(60req/min)으로 미국 실적·IPO 일정을 수집한다.

**Finnhub API 키 관리 (신규):**
- `aiCredentialStore.js`에 `finnhubApiKey` 필드 추가
- `src/components/settings/FinnhubKeyPanel.jsx` 생성
- `Settings.jsx`에 FinnhubKeyPanel 마운트

**서버 엔드포인트 추가:**
```
GET /api/finnhub/calendar/earnings?from=2026-06-01&to=2026-06-30
  → Finnhub /calendar/earnings 프록시 (x-finnhub-token 헤더 사용)
  → EPS estimate, 발표 시간(BMO/AMC) 포함 반환

GET /api/finnhub/calendar/ipo?from=2026-06-01&to=2026-06-30
  → Finnhub /calendar/ipo 프록시
```

**변환 결과 형식:**
```js
{
  title: 'Apple 2Q 실적 발표 (BMO)',
  date: '2026-07-24',
  category: 'earnings',
  ticker: 'AAPL',
  market: 'NASDAQ',
  impact: 'high',
  source: 'finnhub',
  memo: 'EPS 예상: $1.42',
}
```

#### 3.1.3 자동 탐색 UI

**MarketCalendar.jsx 상단 툴바에 자동 탐색 버튼 추가:**

```
[자동 탐색 ▾]  → 드롭다운: [이번 달] [다음 달] [향후 3개월]
```

탐색 결과는 `FetchPreviewModal`에서 미리보기 후 선택 저장한다.

**FetchPreviewModal.jsx (신규):**
- 탐색된 이벤트 목록 표시 (소스 배지: DART / Finnhub)
- 개별 체크박스로 저장할 이벤트 선택
- 중복 이벤트 감지 (동일 ticker + date + category → 스킵 또는 덮어쓰기 선택)
- [선택 저장] 버튼 → `calendarStore.bulkAddEvents()` 호출

### 3.2 매매일지 연계

**EventDetailModal.jsx에 '일지 작성' 버튼 추가:**

조건: 이벤트에 `ticker`가 있을 때만 버튼 표시.

```jsx
{event.ticker && (
  <button onClick={handleOpenJournal}>
    일지 작성
  </button>
)}
```

**동작 흐름:**
1. '일지 작성' 클릭
2. `navigate('/journal', { state: { prefill: { ticker, date, memo: event.title } } })`
3. Journal 페이지에서 `location.state?.prefill` 감지 → JournalEntryForm에 날짜·종목 사전 입력
4. Journal 페이지가 이미 `location.state`를 사용하는지 확인 후 충돌 없이 적용

### 3.3 임팩트 등급 UI 강화

현재 데이터 구조에는 `impact: 'high' | 'medium' | 'low'` 필드가 있지만, 월간·주간 뷰에서 시각적으로 충분히 표현되지 않는다.

**CalendarMonthView.jsx — FullCalendar eventContent 커스텀:**

```
이벤트 렌더링 예시:
[● 삼성전자 실적 ★★★]   (impact: high)
[● 배당락일      ★★ ]   (impact: medium)
[● 주주총회      ★  ]   (impact: low)
```

**CalendarWeekView.jsx — 이벤트 카드 좌측 임팩트 바 추가:**
- `high` → 좌측 빨간 4px 바
- `medium` → 좌측 노란 4px 바
- `low` → 좌측 초록 4px 바

**MarketCalendar.jsx — 임팩트 필터 버튼 추가:**
```
[전체] [★★★ 높음] [★★ 중간] [★ 낮음]
```

### 3.4 브라우저 알림

Web Notifications API 기반 (ServiceWorker 없는 클라이언트 사이드 스케줄링).

- 페이지 로드 시 권한 확인 (`Notification.permission`)
- 캘린더 페이지 진입 시 당일 + 익일 이벤트 체크 후 알림 스케줄
- `impact: 'high'` 이벤트만 기본 알림 (설정에서 조정 가능)

**알림 설정 (`settingsStore.js` 추가):**
```js
calendarNotification: {
  enabled: false,
  timing: 'sameDay',          // 'sameDay' | 'dayBefore'
  impactFilter: 'high',       // 'all' | 'high' | 'highAndMedium'
}
```

**`src/utils/calendarNotifier.js` (신규):**
- `requestPermission()` — 알림 권한 요청
- `scheduleNotifications(events, settings)` — 이벤트 배열 → setTimeout 스케줄
- `cancelAll()` — 예약된 알림 취소

**Settings.jsx — 알림 설정 섹션 추가:**
- 알림 켜기/끄기 토글
- 알림 시점 선택 (당일 아침 09:00 / 전날 밤 21:00)
- 임팩트 등급 필터 선택

## 4. 데이터 구조 변경

### 4.1 calendarEvents IDB 스키마 — 변경 없음

기존 스키마가 `source`, `impact`, `ticker` 필드를 모두 포함하므로 IDB 마이그레이션 불필요.

### 4.2 aiCredentialStore 확장 (수정)

```js
// 추가 필드
finnhubApiKey: null,
finnhubSavedAt: null,

// 추가 액션
setFinnhubKey: async (key) => { ... },
clearFinnhubKey: async () => { ... },
hasFinnhubKey: () => { ... },
```

IDB 저장 시 `provider: 'finnhub'` 사용 (`getAiCredential` 기존 함수 재사용).

### 4.3 settingsStore 확장 (수정)

```js
calendarNotification: {
  enabled: false,
  timing: 'sameDay',
  impactFilter: 'high',
}
```

### 4.4 calendarStore 확장 (수정)

```js
// 신규 액션
fetchFromDart: async (startDate, endDate) => { ... },
fetchFromFinnhub: async (startDate, endDate) => { ... },
bulkAddEvents: async (events) => { ... },  // source+ticker+date+category 중복 제거 포함

// 신규 상태
isFetching: false,       // 자동 탐색 로딩 상태
fetchResult: null,       // 탐색 결과 임시 저장 (FetchPreviewModal용)
filterImpact: 'all',     // 임팩트 등급 필터 (신규)
```

## 8. 제약 및 고려사항

| 항목 | 내용 |
|-----|------|
| DART 배당 일정 | 배당기준일은 공시 후 발표되므로 미래 예정 일자 조회에 한계가 있다. 공시 기반 탐색으로 접근. |
| Finnhub 무료 플랜 | 60 req/min 제한. 범위를 1개월 이내로 제한하고 응답 캐싱 적용. |
| 브라우저 알림 | 페이지가 닫혀있으면 알림 발송 불가. ServiceWorker 없는 단순 구현으로 제한. |
| 중복 이벤트 | 자동 탐색 + 수동 추가 혼재 시 중복 가능. `source + ticker + date + category` 조합으로 감지. |
| Journal prefill | Journal 페이지의 `location.state` 기존 사용 여부 구현 전 확인 필요. |
