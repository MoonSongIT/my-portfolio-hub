## 수동 테스트 시나리오

### 시나리오 A — 이벤트 추가 기본 흐름
1. 사이드바 '증시 일정' 클릭 → 캘린더 페이지 진입
2. `[+ 일정 추가]` 클릭 → 모달 열림
3. 날짜: 오늘 / 제목: '테스트 실적' / 카테고리: 실적 / 임팩트: 높음 입력
4. 저장 → 월간 뷰에서 오늘 날짜에 파란 도트 확인

### 시나리오 B — 뷰 전환
1. 월간 뷰에서 연간 뷰 버튼 클릭 → 히트맵 표시 확인
2. 이벤트 있는 날 셀 클릭 → 해당 월 월간 뷰 이동 확인
3. 주간 뷰 버튼 클릭 → 이번 주 이벤트 카드 표시 확인

### 시나리오 C — 필터
1. 이벤트 여러 개 추가 (실적 1개, 배당 1개)
2. '실적' 필터 클릭 → 실적 이벤트만 표시
3. '배당' 필터 클릭 → 배당 이벤트만 표시
4. '전체' 클릭 → 모두 표시

### 시나리오 D — 편집/삭제
1. 이벤트 클릭 → EventDetailModal 열림
2. 제목 수정 후 저장 → 캘린더에서 수정된 제목 확인
3. 삭제 → 확인 다이얼로그 → 캘린더에서 제거 확인

### 시나리오 E — 영속성
1. 이벤트 추가 후 페이지 새로고침
2. 캘린더에 이벤트 그대로 표시 확인
