# 포트폴리오 페이지 개선 계획

## Context

사용자 요청 기반 5가지 개선 + 내부 분석 기반 2가지 추가 개선.
현재 포트폴리오 페이지는 기본적인 보유 종목 표시와 차트는 갖췄으나,
오늘 손익 가시성, 종목별 추이 시각화, 계좌별 분리, 업종 데이터 정확도에 공백이 있음.

---

## 개선 항목

### [A] 오늘 추정손익 KPI 카드 추가 *(사용자 요청)*

**파일:** `src/pages/Portfolio.jsx`

- `calcMorningComparePnl(holdings, batchData, exchangeRate)` 함수 이미 존재
- `batchData`도 `useBatchQuotes`로 이미 수집 중
- KPI 카드 3개 → 4개로 확장 (그리드 `sm:grid-cols-3` → `sm:grid-cols-2 lg:grid-cols-4`)
- 표시 내용: 오늘 추정손익 금액(원) + 등락률(%)
- 색상: 양수 emerald / 음수 red (기존 KPI 스타일 동일)

---

### [B] 보유 종목 테이블 — 종목별 스파크라인 추가 *(사용자 요청)*

**파일:** `src/components/portfolio/PortfolioTable.jsx` + 신규 `src/components/charts/HoldingSparkline.jsx`

- PortfolioTable 각 행 수익률% 컬럼 다음에 스파크라인 컬럼 추가
- `useDailyPnlStore`에서 `ticker + accountId` 기준 snapshots 필터
- 보유 첫날 기준: 해당 종목의 첫 매수일 이후 데이터만 표시
- 데이터 없으면 "—" 표시 (히스토리 미로드 상태)
- Recharts `LineChart` (이미 설치됨) 사용, 너비 80px · 높이 32px
- 축/라벨/눈금 없는 미니 차트, 최종 수익률 양수면 emerald, 음수면 red

---

### [C] 수익률 추이 차트 — 계좌별 분리 *(사용자 요청)*

**파일:** `src/pages/Portfolio.jsx`

**현재 문제:** `selectedAccountId === 'all'`일 때 전체 계좌 종목이 하나의 차트에 혼재됨.

**개선 방안:**
- `selectedAccountId === 'all'`이고 계좌가 2개 이상이면 계좌별로 `HoldingPnlTimeline` 각각 렌더링
- 각 차트 상단에 계좌명 레이블 표시
- 단일 계좌 선택 시 기존과 동일 (차트 1개)

---

### [D] 수익률 추이 — 툴팁 종목명 표시 + 수익률 정렬 *(사용자 요청)*

**파일:** `src/components/charts/HoldingPnlTimeline.jsx`

**현재 문제:**
1. `<Line name={ticker}>` → 툴팁 p.name이 ticker 코드로 표시됨
2. 툴팁 payload가 렌더 순서(임의) 그대로 나열됨

**수정:**
1. `<Line name={tickerNames[ticker] || ticker}>` 로 변경 → 툴팁에 종목명 표시
2. `CustomTooltip` 내 payload를 value 내림차순 정렬 후 렌더링

---

### [E] 업종별 배분 — sector 하드코딩 수정 *(사용자 요청 + 내부 문제)*

**현재 문제:**
- `portfolioStore.getSelectedHoldings()` 에서 `sector: 'ETC'` 하드코딩 (line 160)
- `journalStore.computeHoldings()` 가 entries에서 sector를 추출하지 않아 유실

**수정:**

1. **`src/store/journalStore.js` — `computeHoldings()`**
   - `map[e.ticker]` 초기화 시 `sector: e.sector || 'ETC'` 포함
   - buy 시 `pos.sector = e.sector || pos.sector` 로 갱신 (최근 매수 sector 우선)

2. **`src/store/portfolioStore.js` — `getSelectedHoldings()`**
   - `sector: 'ETC'` 줄 제거 → journalStore에서 온 sector 그대로 통과

---

### [F] 보유 종목 테이블 — 평가손익(원) 컬럼 추가 *(내부 판단)*

**파일:** `src/components/portfolio/PortfolioTable.jsx`

- 현재 테이블: 평가금액, 수익률%, 비중%는 있으나 손익 금액(원) 없음
- `calculatePositionPnL` 함수 이미 존재 → 바로 활용
- 수익률% 컬럼 앞에 평가손익(원) 컬럼 삽입
- 색상: 양수 emerald / 음수 red

---

### [G] 집중도 경고 — 단일 종목 30% 초과 하이라이트 *(내부 판단, CLAUDE.md 명시)*

**파일:** `src/components/portfolio/PortfolioTable.jsx`

- 비중(weight) > 30%인 행: 노란 배경(`bg-yellow-50`) + 비중 컬럼에 ⚠ 아이콘
- 30% 이하 종목은 기존 스타일 유지

---

## 구현 순서

```
Step 1. [E] sector 하드코딩 수정 (journalStore + portfolioStore)
        검증: 자산 배분 > 업종별 파이차트에 실제 업종명 표시

Step 2. [D] 툴팁 종목명 + 정렬 (HoldingPnlTimeline)
        검증: 호버 시 종목명 노출, 수익률 내림차순 나열

Step 3. [A] 오늘 추정손익 KPI 카드 (Portfolio.jsx)
        검증: KPI 4번째 카드 표시 및 색상

Step 4. [F] 평가손익 컬럼 추가 (PortfolioTable)
        검증: 테이블 손익 금액 노출

Step 5. [G] 집중도 경고 (PortfolioTable)
        검증: 30% 초과 종목 행 강조

Step 6. [B] 스파크라인 (HoldingSparkline 신규 + PortfolioTable 연결)
        검증: 각 행 수익률 컬럼 옆에 미니 차트 표시

Step 7. [C] 수익률 추이 계좌별 분리 (Portfolio.jsx)
        검증: 전체 선택 시 계좌별 차트 분리 렌더링
```
