## [FEAT-01] 대시보드 수익률 추이 차트 — 투자원금+손익 누적 막대 오버레이

> 1차 구현(일간 증감 %p 막대)은 의도와 달라 누적 스택 막대로 재구현. 적용 범위는 대시보드 차트로 한정(포트폴리오 꺾은선 원복).

### 코드 수정

- [x] `ProfitLineChart.jsx` — AreaChart → ComposedChart 교체
- [x] `ProfitLineChart.jsx` — 우측 YAxis를 금액 축(formatCurrencyShort, domain=[0,max])으로 변경
- [x] `ProfitLineChart.jsx` — 파생 데이터(principalBase, pnlSegment, pnl) 계산 추가
- [x] `ProfitLineChart.jsx` — 단일 Bar → principalBase + pnlSegment 스택 막대(stackId)로 교체
- [x] `ProfitLineChart.jsx` — 상단 세그먼트 Cell 색상 분기: pnl ≥ 0 → #EF4444, < 0 → #3B82F6
- [x] `ProfitLineChart.jsx` — Tooltip: 누적 수익률 / 투자원금 / 손익합계 / 총 평가액 표시
- [x] `HoldingPnlTimeline.jsx` — 1차 일간 증감 Bar 원복 (적용 범위 제외)

### 수작업 검증

- [ ] 대시보드 > 수익률 추이 차트에서 막대가 Area 아래 깔리고 Area 선이 위에 보이는지 확인
- [ ] 막대 하단(회색)=투자원금, 상단(빨강=이익/파랑=손실)로 구분되는지 확인
- [ ] 손익 양수일 때 막대 전체 높이 = 총 평가액, 음수일 때 = 투자원금인지 확인
- [ ] 우측 Y축이 금액(원) 단위로 표시되는지 확인
- [ ] Tooltip hover 시 누적 수익률 / 투자원금 / 손익합계 / 총 평가액 모두 표시되는지 확인
- [ ] 기간 선택(7일 / 30일 / 90일) 변경 시 막대도 함께 갱신되는지 확인
- [ ] 포트폴리오 > 꺾은선 차트가 막대 없이 원래 종목별 라인 형태로 돌아왔는지 확인
