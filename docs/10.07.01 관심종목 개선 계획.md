## 1. 배경 및 목적

현재 관심종목 페이지는 실시간 가격 조회, 가격 알림(이상/이하), 카드·테이블 뷰 전환, AI 브리핑 등 기본 기능을 갖추고 있다. 그러나 네이버 금융·TradingView·키움증권 HTS·Yahoo Finance 등 주요 서비스 대비 아래 영역이 부족하다.

- **그룹 관리 없음** — 모든 종목이 단일 플랫 리스트
- **목표가 추적 없음** — 메모 필드(자유 텍스트)만 있어 구조화 불가
- **알림 이력 없음** — 발동 후 토스트만 표시, 히스토리 유실
- **추가일 기준 성과 없음** — `addedAt` 필드는 있으나 수익률 미계산
- **재정렬 불가** — 순서 고정, 드래그앤드롭 미지원

## 3. 확정 사항

| 항목 | 결정 |
|------|------|
| 그룹 방식 | 복수 태그 (1종목에 여러 태그 — TradingView 방식) |
| 스프린트 범위 | Phase A + B + C 전체 |
| 목표가·알림 연동 | 완전 독립 (목표가 트래킹 ≠ 가격 알림) |

## 4. 개선 항목

### Phase A — 그룹(태그) 관리 + 목표가 트래킹

#### A-1. 복수 태그 관리
- 태그 CRUD (생성·이름변경·삭제, 최대 10개), 색상 선택
- 종목에 복수 태그 부착·해제
- 태그 필터 탭 UI (전체 + 태그별)

**스토어 데이터 구조:**
```js
groups: [{ id: 'uuid', name: '성장주', color: '#6366f1', createdAt: '2026-05-15T09:00:00.000Z' }]
// watchlist item 추가 필드
groupIds: ['uuid1', 'uuid2']
```

#### A-2. 목표가·손절가 트래킹 (알림과 독립)
- 종목별 목표가, 손절가, 참고 매입가 입력
- 달성률 프로그레스 바 시각화
- 손절가 대비 안전 여부 표시

**스토어 데이터 구조:**
```js
// watchlist item 추가 필드
targetPrice: 80000, stopLoss: 68000, entryPrice: 72000, priceAtAdded: 72000
```

**UI 스케치:**
```
삼성전자        ↑+2.5%
목표가 80,000  [=========>  ] 94%  +6.7% 남음
손절가 68,000  현재가 안전 ✅
```

---

### Phase B — 알림 고도화

#### B-1. 알림 발동 이력
- 알림 발동 시 `alertHistory`에 append (최대 100건)
- 벨 아이콘 클릭 → Sheet 드로어 오픈
- 읽음/안 읽음 표시

**스토어 데이터 구조:**
```js
alertHistory: [{
  id: 'uuid', ticker: '005930', name: '삼성전자',
  condition: 'above', targetPrice: 75000, actualPrice: 75200,
  firedAt: '2026-05-15T10:30:00.000Z', read: false
}]
```

#### B-2. 알림 일시정지·재개
- 알림별 `paused: boolean` 필드
- `AlarmDialog`에서 토글 스위치
- 일시정지 알림은 체크 건너뜀 + 회색 배지

---

### Phase C — 성과 분석 + 편의기능

#### C-1. 추가일 기준 수익률
- 종목 추가 시 `priceAtAdded` 자동 스냅샷
- 카드·테이블 뷰에 "추가 후 수익률" 배지 (예: `since +12.3%`)

#### C-2. 섹터 분포 미니 파이차트
- 상단 접을 수 있는 섹터 분포 (Recharts 재사용)

#### C-3. 드래그앤드롭 재정렬
- `@dnd-kit` 사용 (이미 설치됨)
- 정렬 기준 선택 중에는 DnD 비활성화

#### C-4. CSV 내보내기
- 브라우저 Blob 다운로드 (서버 불필요)
- 컬럼: 티커, 종목명, 시장, 현재가, 추가일, 메모, 목표가, 손절가
