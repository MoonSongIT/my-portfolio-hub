## Sprint 10.6.1 — Discovery Panel + 최근 본 종목 + 시장 필터 탭

### A. Discovery Panel (탐색 홈 화면)

#### 설계 결정

`Research.jsx`에서 `query === ''` 일 때 검색 결과 그리드 대신 Discovery Panel 표시.  
세 섹션: **최근 본 종목** / **인기 검색어** / **시장 요약**.

```
Research.jsx
 ├─ query === '' → Discovery Panel
 │       ├─ RecentlyViewedSection  (localStorage 'recentlyViewedStocks' 읽기)
 │       ├─ PopularTickersSection  (하드코딩 상수)
 │       └─ MarketSummarySection   (useStockPrice × 3)
 └─ query !== '' → 기존 SearchResultCard 그리드
```

**시장 요약 지수 티커**

| 카드 | 티커 | market |
|------|------|--------|
| KOSPI | `^KS11` | `KRX` |
| NASDAQ | `^IXIC` | `NASDAQ` |
| S&P 500 | `^GSPC` | `NYSE` |

> `useStockPrice`가 `^` 지수 티커를 정상 처리하는지 구현 시 검증 필요. 실패 시 하드코딩 fallback 표시.

**인기 검색어 초기 목록 (하드코딩)**

### D. 종목 비교 패널

#### 설계 결정

수익률 비교: 첫 번째 close 기준 % 변화율 정규화.

```
StockDetail.jsx
 ├─ 헤더: "비교" 버튼 (compareMode 토글)
 └─ compareMode === true → <StockComparePanel> 렌더링 (차트 아래)
      ├─ 비교 종목 검색 (useStockSearch 재사용)
      ├─ 수익률 비교 차트 (Recharts LineChart, % 정규화)
      │   └─ 기간: 1mo / 3mo / 6mo / 1y
      └─ 지표 비교 테이블 (PER/PBR/ROE/시총/52주 고저)
```

**% 정규화 함수**
```js
const normalize = (history) => {
  if (!history?.length) return []
  const base = history[0].close
  return history.map(h => ({
    date: h.date,
    pct: +((h.close - base) / base * 100).toFixed(2)
  }))
}
```

  ```js
  // localStorage 키: 'stockNotes'
  // { [ticker]: { memo: string, updatedAt: ISO-8601 } }
  function loadStockNote(ticker) {
    const notes = JSON.parse(localStorage.getItem('stockNotes') || '{}')
    return notes[ticker]?.memo ?? ''
  }
  function saveStockNote(ticker, memo) {
    const notes = JSON.parse(localStorage.getItem('stockNotes') || '{}')
    notes[ticker] = { memo, updatedAt: new Date().toISOString() }
    localStorage.setItem('stockNotes', JSON.stringify(notes))
  }
  ```
