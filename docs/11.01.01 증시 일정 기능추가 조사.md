# 증시 일정 기능 추가 조사

> 작성일: 2026-05-22  
> 목적: 대시보드 다음 메뉴로 '증시 일정' 추가를 위한 경쟁 사이트 조사 및 기능 설계 방향 도출

---

## 1. 개요

### 1.1 추가 배경

현재 사이드바 메뉴 구성: 대시보드 → 포트폴리오 → 자금 관리 → 매매 일지 → 종목 탐색 → 관심종목 → 리포트 → AI 분석

**신규 메뉴 위치:** 대시보드 바로 다음 (2번째 메뉴)

**핵심 사용 시나리오:**
- 이번 주 / 이번 달에 어떤 실적 발표가 있는지 확인
- 보유 종목의 배당락·배당지급일 파악
- 관심 종목의 IPO·상장 일정 확인
- 주요 경제지표 발표일 파악 (미 FOMC, CPI, 고용지표 등)
- 개인 메모(수동 일정) 추가

## 2. 경쟁 사이트 분석

### 2.1 글로벌 서비스

#### TradingView — Calendar Suite
- **URL:** https://www.tradingview.com/economic-calendar/
- **구성:** Economic Calendar / Earnings Calendar / Revenue Calendar / Dividend Calendar / IPO Calendar (5가지 독립 탭)
- **핵심 UI 특징**
  - 30만 개 이상의 경제지표, 190개국 커버
  - 이벤트별 충격 등급: ★ / ★★ / ★★★ (낮음 / 중간 / 높음)
  - 실제값과 예측값 비교: 초과(초록) / 미달(빨강) 색상 코딩
  - SuperChart 통합: 차트 타임라인 위에 이벤트 마커 직접 표시
  - 국가 / 시간대 / 기간 필터 제공
- **강점:** 경제지표 데이터 폭이 매우 넓음, 차트와 통합
- **약점:** 한국 기업 공시·실적 데이터 상대적으로 약함

#### Investing.com — Economic & Earnings Calendar
- **URL:** https://www.investing.com/economic-calendar/
- **구성:** 경제 캘린더 / 실적 캘린더 / IPO 캘린더
- **핵심 UI 특징**
  - 3단계 임팩트 불꽃 아이콘 (🔥 / 🔥🔥 / 🔥🔥🔥)
  - 이전값 / 예측값 / 실제값 3열 비교 표시
  - 필터: 국가, 중요도, 카테고리 (통화정책·무역·고용·인플레이션 등)
  - 실시간 업데이트 (발표 즉시 색상 변경)
- **강점:** 실시간성, UI 완성도 높음, 국내 투자자 인지도 높음
- **약점:** 한국 공시 데이터 연동 없음

#### Yahoo Finance — Financial Calendars
- **URL:** https://finance.yahoo.com/calendar/
- **구성:** Earnings / Economic / IPO / Splits
- **핵심 UI 특징**
  - 날짜별 리스트 뷰 중심 (캘린더 그리드 없음)
  - EPS 예측 / 실제 / 서프라이즈 % 표시
  - 관심 종목과 연동하여 해당 종목만 필터링 가능
- **강점:** 미국 주식 데이터 완성도 높음
- **약점:** 캘린더 그리드 뷰 없음, 한국 주식 미지원

### 2.2 국내 서비스

#### 토스증권 — 증시 캘린더
- **URL:** https://www.tossinvest.com/calendar
- **특징**
  - 월간 캘린더 그리드 뷰 제공 (날짜 칸에 이벤트 도트 표시)
  - 탭: 실적 / 배당 / 공시 / IPO
  - 실적: EPS 예측 vs 실제, 시가총액 기준 정렬
  - 관심 종목 필터: 전체 / 내 관심 종목만
  - 모바일 최적화 UX
- **강점:** 한국 주식 데이터 강점, 깔끔한 UI, 월간 그리드 뷰
- **약점:** 경제지표(매크로) 데이터 없음, 연간·주간 뷰 없음

#### KB증권 — 리서치 캘린더
- **URL:** https://rc.kbsec.com/calendar/calendarView.able
- **특징**
  - 애널리스트 리포트 발간 일정과 연계
  - 실적 발표 / 기업 IR 일정 포함
  - 그리드 캘린더 뷰
- **강점:** 증권사 리서치와 연계된 깊이 있는 일정 정보
- **약점:** KB증권 회원 전용

#### 신한투자증권 — 증시캘린더
- **URL:** https://www.shinhansec.com/siw/banking-lending/subscribe/finance-Calendar/view.do
- **특징**
  - 유상증자·청약 일정 강점
  - 주별/월별 보기 전환
  - 이벤트 유형별 색상 구분
- **강점:** 청약·증자 일정 상세
- **약점:** 전반적인 UI 다소 복잡

#### KIND (KRX 기업공시) — 주식 일정
- **URL:** https://kind.krx.co.kr/common/stockschedule.do
- **특징**
  - 공식 기업공시 채널 (배당, 증자, 주식병합 등)
  - 월간 캘린더 뷰
  - 데이터 신뢰도 최고 (거래소 공식)
- **강점:** 공식 데이터, 배당·권리락·청약 완전 커버
- **약점:** UI 구식, 실적발표 일정 없음

#### 키움증권 / FnGuide — 실적발표 캘린더
- **키움:** https://invest.kiwoom.com/inv/calendar
- **FnGuide:** https://comp.fnguide.com/SVO2/ASP/SVD_comp_calendar.asp
- **특징**
  - 종목별 실적 발표 예정일 제공
  - 컨센서스 EPS / 매출액 예측 포함
  - 분기별 실적 히스토리 연계

## 4. 데이터 수집 방법 비교

### 4.1 자동 탐색 (API 연동)

| API | 커버리지 | 무료 한도 | 비고 |
|-----|---------|---------|-----|
| **DART OpenAPI** | 한국 공시 (배당, 증자, 실적) | 무제한 | 금융감독원 공식 |
| **KRX OpenAPI** | 국내 IPO, 상장, 배당 | 무제한 | 거래소 공식 |
| **Finnhub** | 미국 실적, IPO, 배당 | 60 req/min | 무료 플랜 |
| **Yahoo Finance** | 미국 실적, 경제지표 | 비공식 (크롤링) | 신뢰도 주의 |
| **Investing.com** | 글로벌 경제지표 | 공개 임베드 | API 없음, 위젯 활용 |

### 4.2 수동 추가

- 사용자가 직접 날짜/제목/카테고리 입력
- IndexedDB(Dexie)에 저장
- 보유 종목 / 관심 종목 연계 태깅 가능

## 7. 구현 방향 제안

### 7.1 MVP 범위 (Phase 1)

**뷰 구성**
- 월간 캘린더 그리드 (기본 뷰)
- 주간 리스트 뷰
- 연간 히트맵 뷰 (이벤트 밀도 표시, GitHub 잔디 스타일)

**이벤트 유형 (우선순위 순)**
1. 실적 발표 (국내 + 미국 주요 종목)
2. 배당락 / 배당지급 일정
3. IPO / 공모주 청약 일정
4. 수동 추가 이벤트

**데이터 수집**
- 수동 추가: IndexedDB 저장 (즉시 구현 가능)
- 자동 탐색: DART OpenAPI (국내), Finnhub (미국) — API 키 등록 후 연동

**관심 종목 연동**
- 관심 종목에 등록된 종목의 이벤트를 강조 표시
- 보유 종목은 별도 색상으로 구분

### 7.2 확장 범위 (Phase 2)

- 경제지표 (FOMC, CPI 등) 표시
- 이벤트 알림 (브라우저 알림)
- 매매일지와 연계 (이벤트 당일 일지 바로 작성)
- 이벤트 임팩트 등급 표시 (★ / ★★ / ★★★)

## 8. 기술적 고려사항

### 8.1 데이터 저장 구조 (IndexedDB 예시)

```javascript
// 증시 일정 이벤트 스키마 (예시)
{
  id: 'evt_001',
  date: '2026-06-15',         // YYYY-MM-DD
  endDate: null,              // 기간 이벤트인 경우
  title: '삼성전자 1Q 실적 발표',
  category: 'earnings',       // earnings | dividend | ipo | economic | custom
  ticker: '005930',           // 연관 종목 티커 (선택)
  market: 'KRX',              // KRX | NYSE | NASDAQ
  impact: 'high',             // high | medium | low
  source: 'manual',           // manual | dart | finnhub | krx
  memo: '',
  isWatchlist: true,          // 관심종목 여부
  isHolding: false,           // 보유종목 여부
  createdAt: '2026-05-22T09:00:00Z'
}
```

### 8.2 API 연동 우선순위

1. **DART OpenAPI** — 무료, 공식, 한국 배당/공시 완전 커버
   - 등록: https://opendart.fss.or.kr/
   - 주요 엔드포인트: `alotMatter` (배당), `irdsSttus` (IR 일정)

2. **Finnhub** — 무료 플랜으로 미국 실적/IPO 충분
   - 등록: https://finnhub.io/
   - 주요 엔드포인트: `/calendar/earnings`, `/calendar/ipo`

3. **KRX OpenAPI** — 국내 IPO 공식 데이터
   - 등록: https://data.krx.co.kr/

### 8.3 기존 시스템 연동 포인트

| 기존 파일 | 활용 방식 |
|---------|---------|
| `src/store/watchlistStore.js` | 관심종목 티커 목록 참조 |
| `src/store/portfolioStore.js` | 보유종목 티커 목록 참조 |
| `src/utils/storage.js` | IndexedDB 헬퍼 확장 |
| `src/api/stockApi.js` | 이벤트 API 메서드 추가 |
| `src/components/common/Sidebar.jsx` | 메뉴 추가 (Calendar 아이콘) |
| `src/App.jsx` | 라우트 추가 (`/calendar`) |

## 9. 벤치마킹 요약 및 차별화 전략

### 현재 시장 공백

| 공백 | 경쟁사 현황 | 우리의 기회 |
|-----|-----------|-----------|
| 수동 이벤트 추가 | 어떤 서비스도 없음 | 개인 일정 관리 차별화 |
| 보유/관심 종목 연동 | 토스만 관심종목 필터 | 매매일지와 연결 가능 |
| 연간 히트맵 뷰 | 없음 | 연간 흐름 파악 가능 |
| 매매일지 직접 연계 | 없음 | 이벤트 → 일지 작성 원클릭 |

### 핵심 차별화 포인트

1. **내 포트폴리오 중심 필터링** — 보유/관심 종목 이벤트만 모아보기
2. **수동 + 자동 혼합** — API로 자동 수집 + 개인 메모 추가 가능
3. **매매일지 연계** — 실적 발표 이후 일지 바로 작성 버튼
4. **연간 히트맵** — GitHub 잔디 스타일로 연간 이벤트 밀도 파악
