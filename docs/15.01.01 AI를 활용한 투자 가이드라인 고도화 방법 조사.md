## Part 2. 미국 선행지표를 활용한 한국 증시 예측 프레임워크

### 2-1. 왜 미국이 한국을 "선행"하는가 — 시차 구조

한국 증시는 구조적으로 미국 증시를 **추종(follow)**한다. 핵심은 **시간대 시차**다.

```
   (한국 장 마감 15:30)
        │
        ▼
   미국 장 개장 22:30~ (서머타임) / 23:30~ (한국시간)
        │   ← 이 사이 미국에서 일어난 모든 것이
        ▼      한국의 "내일 개장"에 선반영된다
   미국 장 마감 05:00~06:00 (한국시간)
        │
        ▼
   한국 장 개장 09:00  ← 미국 결과를 갭(Gap)으로 흡수
```

즉 미국의 밤 = 한국의 새벽이고, 한국 투자자가 자는 동안 결정된 미국의 방향이 한국 개장 갭으로 전이된다. 이 전이를 **사전에 정량화**하는 것이 선행지표 활용의 본질이다.

### 2-2. 선행지표 계층 (Tier)

선행성·전달력 순으로 4계층으로 분류한다. 괄호는 Yahoo Finance 등에서 조회 가능한 티커다.

#### Tier 1 — 직접 전이 (당일 갭에 즉시 반영)

| 지표 | 티커 | 한국 전달 경로 |
|------|------|---------------|
| S&P500 | `^GSPC` | 전체 위험선호 → 코스피 갭 방향 |
| 나스닥 100 | `^IXIC` / `^NDX` | 성장주·기술주 심리 → 코스닥·성장주 |
| **필라델피아 반도체(SOX)** | `^SOX` (또는 ETF `SOXX`) | **삼성전자·SK하이닉스·한미반도체에 직접 연동**. SOX는 시장 대비 약 3개월 선행한다는 분석(Oxford Economics)이 있을 만큼 경기·기술 사이클의 선행지표 |
| 코스피200 야간선물 | (CME/EUREX 연계, 별도 소스 필요) | 한국 개장 방향의 **가장 직접적 프록시**. 단 무료 조회가 까다로움 |

> 반도체가 코스피 시가총액의 큰 비중(삼성전자+SK하이닉스)을 차지하므로, **SOX는 한국 증시에 가장 실효적인 단일 선행지표**다. Tier 1 중 우선 도입 1순위.

#### Tier 2 — 변동성·심리 (방향보다 "강도"를 예고)

| 지표 | 티커 | 의미 |
|------|------|------|
| **VIX (공포지수)** | `^VIX` | S&P500 옵션 내재변동성. VIX 급등 = 위험회피 = 외국인 자금 이탈 압력. 변동성 레짐 분류의 핵심 입력(Part 3) |
| VVIX | `^VVIX` | VIX의 변동성. 변동성 자체의 불안정성 |
| Put/Call 비율, Fear&Greed | (보조) | 군중 심리 과열·공포 |

#### Tier 3 — 자금·거시 채널 (외국인 수급을 좌우)

| 지표 | 티커 | 전달 경로 |
|------|------|----------|
| **미국채 10년물 금리** | `^TNX` | 글로벌 할인율. 한미 금리차 확대 → 외국인 한국 비중 축소 유인 |
| **달러 인덱스(DXY)** | `DX-Y.NYB` | 강달러 = 신흥국·한국 자금 유출 |
| **원/달러 환율** | `KRW=X` | 외국인 환손실 우려 → 순매도. 2026년 6월 현재 1,540원대, 외국인 누적 약 20조원 순매도가 핵심 수급 악재 |
| WTI 유가 | `CL=F` | 인플레·무역수지(한국은 수입국) |

> 2026년 현재 한국 증시는 **고환율·외국인 매도**가 변동성의 진앙이다(검색 근거). 따라서 Tier 3(특히 원/달러·미국채)는 단순 보조가 아니라 **현 국면의 1급 변수**다.

#### Tier 4 — 매크로 이벤트 (주기적, 캘린더 연동)

미국 ISM 제조업 PMI, 비농업 고용(NFP), CPI, FOMC. 이들은 발표 시점이 정해져 있어 **증시 일정 캘린더(Phase 11)와 결합**하면 "내일 새벽 미국 CPI → 한국 장 변동성 주의" 식의 사전 경고가 가능하다.

### 2-3. 선행 신호 → 한국 방향 변환 (개념 모델)

복잡한 ML 없이도, 다음과 같은 **규칙 기반 스코어**로 1차 신호를 만들 수 있다. 이는 AI에게 줄 "구조화된 근거"의 역할을 한다.

```
overnightBias =  w1·sign(SOX 등락률)
              +  w2·sign(S&P500 등락률)
              +  w3·(-sign(VIX 변화))      ← VIX 상승은 음(-)의 신호
              +  w4·(-sign(원달러 변화))    ← 환율 상승은 음(-)의 신호
              +  w5·(-sign(US10Y 변화))
   → 합산 점수를 [강한 하락 / 약세 / 중립 / 강세 / 강한 상승] 5단계로 매핑
```

> 핵심 설계 원칙: 이 점수는 **결정이 아니라 "가설(hypothesis)"**이다. AI 에이전트가 이 점수 + 실제 뉴스·공시를 종합해 **확률적 시나리오**로 서술하게 한다. 가중치 `w`는 고정 상수로 시작하고, 사후 검증(Part 4-3)으로 보정한다.

## Part 3. 변동성 레짐 분석 — 최근 장세 대응 기법

요구의 핵심인 "변동성이 심한 최근 장세에 적용 가능한 기법"을 다룬다.

### 3-1. 변동성 레짐(국면) 분류

시장을 **저변동 / 정상 / 고변동 / 위기**의 상태로 분류하고, 상태마다 다른 전략·리스크 파라미터를 적용하는 것이 2025~2026 퀀트 실무의 표준이다.

#### 방법 A — VIX 백분위 (권장: 투명·해석가능)

최근 연구는 잠재상태 모델(HMM)보다 **VIX 롤링 백분위** 방식을 실무에서 더 선호한다(해석 가능성·적응성). 방식은 단순하다.

```
지난 252거래일(1년) VIX 분포에서
  - 현재 VIX < 33 백분위  → 저변동 레짐
  - 33 ~ 67 백분위        → 정상 레짐
  - > 67 백분위           → 고변동 레짐
  - 절대값 + 급변(예: VIX 1일 +20%) → 위기 레짐
```

장점은 **계산이 가볍고**(브라우저에서 즉시), **블랙박스가 아니며**, 미래 데이터를 끌어쓰지 않으면(rolling) look-ahead bias가 없다는 점이다. 본 프로젝트의 클라이언트 사이드 계산 구조에 가장 적합하다.

#### 방법 B — Hidden Markov Model (HMM)

2~3개 잠재상태를 자동 추정. 21년 백테스트에서 연 19.41%·샤프 1.22·MDD 19.54%의 결과가 보고된다. 다만 라이브러리 의존·룩어헤드 통제(rolling/online fitting 필수)·해석 난이도 때문에 **본 프로젝트 1차 범위에는 과하다**. 향후 서버사이드 배치로 검토.

### 3-2. 레짐별 행동 가이드 (AI가 제시할 프레임)

| 레짐 | 시장 성격 | 일반적 대응 원칙(가이드) |
|------|----------|------------------------|
| 저변동 | 추세 지속, 낮은 공포 | 추세 추종 유효, 평소 포지션 |
| 정상 | 균형 | 기본 전략 유지 |
| **고변동** | 급등락 빈발 | **포지션 축소·분할 강화**, 손절폭(ATR 기반) 확대, 신규 진입 신중 |
| **위기** | 패닉·상관 붕괴 | **현금 비중 확대 검토**, 추격 금지, 변동성 진정 신호 대기 |

> 이는 모두 "원칙·체크포인트" 제시이지 매매 지시가 아니다. PortfolioAgent/AlertAgent 사양("매도/매수 직접 추천 금지, 검토 포인트만 제시")과 정합한다.

### 3-3. 변동성 정량 지표 — 기술지표 확장

현재 `technicalApi.js`는 추세 지표(MA/RSI/MACD) 중심이다. 변동성 장세 대응을 위해 **변동성 지표**를 추가하는 것이 자연스럽다.

| 지표 | 용도 | 구현 난이도 |
|------|------|------------|
| **ATR (Average True Range)** | 종목 고유 변동성 → 손절폭·포지션 사이징 기준 | 낮음 (순수 함수, 기존 패턴과 동일) |
| **볼린저밴드 폭(%B, Bandwidth)** | 변동성 수축/확장(스퀴즈→돌파) 감지 | 낮음 |
| **종목 실현변동성(σ, 20일)** | 포트폴리오 리스크 집계 | 낮음 |
| 히스토릭 VaR | 포트폴리오 최대 예상 손실 | 중간 (Reports에서 일부 KPI 존재) |

ATR·볼린저는 `computeIndicators`에 함수 1~2개를 더하는 수준으로, 14.04와 동일한 순수 함수 패턴으로 추가 가능하다.

## Part 4. AI 분석 고도화 — 과학적 투자 가이드라인

선행지표(Part 2)·변동성 레짐(Part 3)을 **AI가 종합해 가이드**하게 만드는 방법이다.

### 4-1. 멀티 에이전트 신호 종합 — `MarketRegimeAgent`(신설 제안)

학계·업계의 LLM 금융 멀티에이전트는 Valuation/Sentiment/Fundamentals/Technicals/**Risk Manager** 에이전트가 신호를 내고 **Portfolio Manager 에이전트가 종합**하는 구조다. 본 프로젝트는 이미 6개 에이전트가 있으므로, 빈자리는 **"거시·시장 국면" 판단자**다.

제안: 7번째 에이전트 **`MarketRegimeAgent`** 신설.

```
입력(프리패치, 구조화):
  - Tier1~3 선행지표 스냅샷 (SOX/S&P/나스닥/VIX/US10Y/DXY/원달러 등락)
  - overnightBias 규칙 점수 (Part 2-3)
  - VIX 백분위 레짐 (Part 3-1)
  - (옵션) web_search로 거시 헤드라인 (14.04 P2)
출력:
  - 오늘의 시장 국면: [방향 5단계] × [변동성 레짐 4단계]
  - 핵심 동인 3가지 (근거 인용)
  - 변동성 레짐별 행동 원칙 (검토 포인트)
  - 확률적 시나리오 (상승/횡보/하락 + 트리거)
  - 면책 문구
```

라우팅 키워드 예: "오늘 시장", "장 전망", "코스피 방향", "선행지표", "변동성". orchestrator에 키워드 + (14.04에서 검토한) LLM 라우팅으로 연결한다.

### 4-2. LLM 그라운딩 데이터 확장

현재 `buildMarketBriefContext`는 지수 4종 + 뉴스만 직렬화한다. 이를 **선행지표 패키지**로 확장한다.

```
[선행지표 스냅샷 — 2026-06-23 08:30 KST]
· S&P500   -1.2% / 나스닥 -1.8% / SOX -2.4%   ← 반도체 약세 선행
· VIX 24.1 (전일 19.8, +21.7%) → 67 백분위 상회 = 고변동 레짐 진입
· 美10Y 4.51% (+6bp) / DXY +0.4% / 원달러 1,541 (+8)
· overnightBias 점수: -3 → "약세" 가설
[거시 헤드라인]  (web_search, 한국 지역화·신뢰도메인 화이트리스트)
...
```

이렇게 **수치를 미리 계산해 텍스트로 주입**하면(프리패치형 RAG), 모델은 산술이 아니라 **해석·서술·시나리오화**에 집중한다 — LLM의 강점에 부합하고 환각을 억제한다. 이는 14.04의 그라운딩 철학을 거시 영역으로 확장한 것이다.

### 4-3. 예측을 "과학적"으로 만드는 3가지 절차

단순히 그럴듯한 서술이 아니라, 검증 가능한 절차로 만든다.

1. **Look-ahead bias 회피** — 레짐·백분위 계산은 항상 "그 시점까지의 데이터(rolling/trailing)"만 사용. 전체 시계열 학습 금지. (검색 근거: 2026 연구들이 rolling·point-in-time을 표준으로 강조)
2. **확률·조건부 표현 강제** — 프롬프트에서 "단정 금지, 확률·조건(트리거) 형태로만 서술". 예: "SOX 약세가 이어지면 반도체주 약세 압력(가능성 높음)" 식.
3. **사후 검증 루프(트래킹)** — 매일의 `overnightBias`/레짐 판단을 저장하고, 실제 코스피 시·종가와 대조해 **적중률을 누적**. 이는 가중치 `w` 보정과 "AI 신뢰도 표시"의 근거가 된다. 14.04에서 다룬 피드백 루프와 동일 사상.

### 4-4. 모델·도구 구성 (14.04 연계)

- **모델**: 거시 종합·다단계 추론은 `claude-opus-4-8`(최고 사양). 14.04 P1에서 제거하기로 한 모델 하드코딩이 전제(`api/claude.js`).
- **확장적 사고(extended thinking)**: 선행지표 5~7종 + 뉴스 종합은 추론 깊이가 필요 → MarketRegimeAgent에 한해 활성 검토.
- **web_search**: 거시·테마 헤드라인 탐색(Part 2 Tier4, 14.04 경로 A·C). `max_uses` 상한 + 캐시로 비용 통제.
