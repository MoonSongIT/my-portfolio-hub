## 수동 테스트 시나리오

### 시나리오 A — Finnhub 자동 탐색
1. Settings → Finnhub API 키 입력 후 저장
2. 증시 일정 → [자동 탐색] → 이번 달 → Finnhub 선택
3. FetchPreviewModal 열림 + 미국 실적/IPO 이벤트 목록 표시 확인
4. 일부 체크박스 해제 후 [선택 저장]
5. 월간 캘린더에서 저장된 이벤트 source='finnhub' 배지 확인

### 시나리오 B — DART 자동 탐색
1. Settings → DART API 키 확인 (기존 저장된 키)
2. 증시 일정 → [자동 탐색] → 이번 달 → DART 선택
3. FetchPreviewModal에 국내 배당/실적 공시 이벤트 표시 확인
4. [선택 저장] → 캘린더 갱신 확인

### 시나리오 C — 매매일지 연계
1. [일정 추가] → 종목 검색창에 "삼성전자" 입력 → 드롭다운에서 선택
   - 입력창이 "삼성전자 (005930)" 형태로 바뀌는지 확인
2. 저장 후 해당 이벤트 클릭 → EventDetailModal
   - 종목 행: "삼성전자 (005930)" 표시 확인
3. [일지 작성] 버튼 클릭 → Journal 페이지 이동
   - 종목코드: `005930`, 종목명: `삼성전자` 사전 입력 확인
4. ticker 없는 이벤트에서는 [일지 작성] 버튼 미표시 확인

### 시나리오 D — 자동 탐색 업서트 (기존 이벤트 종목명 보완)
1. Finnhub 자동 탐색으로 이벤트를 저장 (이 시점에서는 name 없이 ticker만 저장될 수도 있음)
2. 같은 기간으로 다시 [자동 탐색] → FetchPreviewModal 열림
3. 기존에 name 없이 저장된 이벤트에 **"업데이트"** (초록-청록 배지) 표시 확인
4. 기존에 name까지 저장된 이벤트에 **"중복"** (노란 배지) 표시 + 체크 해제 상태 확인
5. [선택 저장] 클릭 → 토스트: `"N건 추가, M건 업데이트되었습니다."` 확인
6. 업데이트된 이벤트 클릭 → 상세 모달에서 종목명 표시 확인

### 시나리오 E — 임팩트 필터
1. 이벤트 여러 개 추가 (high/medium/low 각 1개씩)
2. 임팩트 필터 [높음 ★★★] 클릭 → high 이벤트만 표시
3. 월간 뷰에서 high 이벤트에 ★★★ 표시 확인

### 시나리오 F — 브라우저 알림
1. Settings → 알림 켜기 → 권한 허용
2. 알림 시점: 당일 09:00, 임팩트: 높음 설정
3. 오늘 날짜에 impact:'high' 이벤트 등록
4. 증시 일정 페이지 진입 → Console에서 스케줄 등록 로그 확인
