# 10.05.01 매매일지(Journal) 현황 분석 및 개선 계획

작성일: 2026-05-13  
스프린트: 10.5.x

---

## 1. 현황 분석

### 1.1 데이터 모델

```js
{
  id: UUID,
  createdAt: ISO 타임스탬프,
  date: 'YYYY-MM-DD',
  accountId: string,         // 계좌 FK
  ticker: string,            // 대문자
  name: string,              // 회사명
  market: 'KRX' | 'NYSE' | 'NASDAQ',
  action: 'buy' | 'sell',
  price: number,
  quantity: number,
  amount: number,            // price × quantity (자동)
  fee: number,               // 수수료 (기본 0)
  psychology: string,        // 아래 심리 카테고리 중 선택
  memo: string,
  pnl: number | null,        // 매도 시 실현 손익
  linkedCashFlowId: string,  // 자금관리 자동 연동
  source: 'eugene-hts' | undefined,
  externalId: string,        // HTS import 중복 방지
}
```

**심리 카테고리**
- 매수: 미래가치 투자, 분할매수 원칙, 추격매매, 뉴스 편승, 저가 매수, 목표가 도달, 기술적 분석(20일상승), 기타
- 매도: 목표가 실현, 손절 원칙, 공포에 매도, 수익 실현(조급), 리밸런싱, 기술적 분석(20일하락), 기타

### 1.2 구현 현황

| 기능 영역 | 상태 | 비고 |
|----------|------|------|
| **기본 CRUD** | ✅ 완료 | 단건 입력, 일괄 입력, 수정, 삭제 |
| **HTS Import** | ⚠️ 부분 | 파서(htsParser.js)는 구현됨, UI 폼 없음 |
| **필터링** | ⚠️ 부분 | 심리·매수/매도·종목·계좌 필터 있음, 날짜 범위 없음 |
| **통계 분석** | ✅ 완료 | 심리별 손익, 승률, 실현손익 합계 |
| **차트** | ✅ 완료 | 심리별 평균 손익 막대차트 |
| **AI 코치** | ✅ 완료 | JournalCoachAgent, 압축 컨텍스트 |
| **데이터 영속** | ✅ 완료 | IndexedDB + Zustand, 전체 백업/복원 |
| **자금관리 연동** | ✅ 완료 | 매수/매도 시 cashFlow 자동 생성 |
| **관심종목 연동** | ✅ 완료 | 매수 시 watchlist 자동 등록 |
| **보유종목 연동** | ✅ 완료 | computeHoldings()가 일지에서 파생 |
| **리포트 연동** | ✅ 완료 | TradeHistoryTable, 손익 분석 |
| **내보내기** | ⚠️ 부분 | PNG/PDF만 있음, CSV/Excel 없음 |
| **중복 방지** | ⚠️ 부분 | HTS import 전용, 수동 입력 미적용 |

---

### 1.3 UX 현황

**잘 된 것**
- 종목 검색 시 최근 거래 3건 힌트 표시
- 최근 매매가/수량 자동 placeholder
- 날짜별 그룹 정렬 (최신순)
- 매수(파랑)/매도(빨강) 색상 구분
- 손익 +/- 색상 표시
- 계좌별 필터 (탭 방식, 2계좌 이상 시 표시)

**UX 갭**
- 날짜 범위 필터 없음 (리포트 페이지에는 있으나 일지 페이지엔 없음)
- HTS 거래내역 import 버튼/UI 없음 (일지 페이지에서 직접 접근 불가)
- 일괄 수정 불가 (항목 하나씩만 수정)
- 메모 내용으로 검색 불가 (종목명/티커만 가능)
- 계좌 선택 UI가 드롭다운이 아닌 커스텀 탭 버튼 (다른 페이지와 불일치)

## 3. 개선 계획

### 3.1 우선순위 HIGH (Sprint 10.5.1)

#### A. 계좌 선택 UI 통일 (완료: 2026-05-13)
**문제:** Journal.jsx의 계좌 선택이 인라인 커스텀 탭 버튼으로 구현되어 있어,
자금관리(CashFlow.jsx)의 AccountSelector 드롭다운과 디자인이 불일치함.  
**해결:** `src/components/account/AccountSelector` (드롭다운)로 교체.  
**영향 파일:** `src/pages/Journal.jsx`  
**참고 기준:** `src/pages/CashFlow.jsx` 패턴

#### B. 날짜 범위 필터 추가
**위치:** `src/pages/Journal.jsx` 필터 영역  
**방법:** 기존 `filterByDateRange()` 유틸 재사용 (`src/utils/calculator.js`)  
**UI:** 1주/1개월/3개월/전체 프리셋 버튼 (리포트 페이지의 DATE_RANGES 패턴 참고)

```
검증: 필터 적용 시 목록·통계·차트 모두 해당 기간 데이터로 갱신
```

#### C. HTS 거래내역 Import UI
**위치:** `src/pages/Journal.jsx` 헤더 버튼 영역  
**방법:** 기존 `src/utils/htsParser.js` + `addEntriesBulk()` 재사용  
**UI:** "HTS Import" 버튼 → 파일 선택 → 미리보기 테이블 → 확인 시 일괄 저장

```
검증: 유진투자증권 Excel 파일로 import 테스트, 중복 항목 건너뜀 확인
```

### 3.2 우선순위 MEDIUM (Sprint 10.5.2)

#### D. 매매일지 CSV 내보내기
**위치:** `src/pages/Journal.jsx` 헤더 버튼 영역  
**방법:** `src/utils/dataExport.js` 패턴 참고, journal entries → CSV 변환  
**출력 컬럼:** 날짜, 계좌, 종목코드, 종목명, 시장, 매수/매도, 가격, 수량, 금액, 수수료, 심리, 메모, 실현손익  
**인코딩:** UTF-8 BOM (Excel 한글 깨짐 방지)

```
검증: 다운로드된 CSV를 Excel에서 열어 한글 정상 출력 확인
```

#### E. 월별/주별 통계 트렌드
**위치:** `src/pages/Journal.jsx` 통계 영역 또는 별도 탭  
**내용:** 월별 거래 건수, 월별 실현손익, 심리별 월간 승률 추이  
**차트:** Recharts BarChart/LineChart (기존 패턴 재사용)

```
검증: 최근 3~6개월 데이터 월별 집계값 journalStore getSummaryStats()와 일치
```
