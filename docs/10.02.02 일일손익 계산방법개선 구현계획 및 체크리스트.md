## Sprint 10.2.1 — calculator.js 신규 함수 추가

> 파일: `src/utils/calculator.js` (수정)

### 10.2.1-A. calcMorningComparePnl 함수

- [x] 함수 시그니처: `calcMorningComparePnl(holdings, batchData, exchangeRate)`
- [x] 반환값: `{ amount: number, rate: number }`
- [x] `batchData` 없을 시 `{ amount: 0, rate: 0 }` 반환
- [x] batchData 순회:
  - [x] `r.success === false` 또는 `r.data?.previousClose` 없으면 skip
  - [x] `holdings.filter(h => h.ticker === r.ticker)` 로 보유종목 매핑
  - [x] KRW 종목: `(currentPrice - previousClose) × quantity`
  - [x] USD 종목: `(currentPrice - previousClose) × quantity × exchangeRate`
- [x] `prevTotal` 누산 (전일 기준 총평가액, rate 계산용)
- [x] 최종 반환:
  ```js
  { amount: Math.round(pnl), rate: prevTotal > 0 ? (pnl / prevTotal) * 100 : 0 }
  ```

### 10.2.1-B. calcRealizedTodayPnl 함수

- [x] 함수 시그니처: `calcRealizedTodayPnl(entries, today)`
- [x] 반환값: `{ amount: number, count: number }`
- [x] `entries.filter(e => e.action === 'sell' && e.date === today)` 필터
- [x] `entry.pnl ?? 0` 합산 (null/undefined 방어)
- [x] 최종 반환:
  ```js
  { amount: Math.round(amount), count: todaySells.length }
  ```

### 10.2.1 완료 검증

- [x] `calcMorningComparePnl` — 전일종가 10,000 / 현재가 10,500 / 수량 100 → amount: 50,000
- [x] `calcMorningComparePnl` — batchData null → `{ amount: 0, rate: 0 }`
- [x] `calcMorningComparePnl` — USD 종목 → exchangeRate 곱셈 적용 확인
- [x] `calcRealizedTodayPnl` — 오늘 매도 2건(pnl: 30,000 / 20,000) → amount: 50,000, count: 2
- [x] `calcRealizedTodayPnl` — 매도 0건 → `{ amount: 0, count: 0 }`
- [x] `calcRealizedTodayPnl` — 다른 날짜 매도 entry는 집계 제외 확인
