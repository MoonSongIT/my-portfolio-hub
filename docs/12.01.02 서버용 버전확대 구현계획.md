## 1. 목표 및 범위

### 1.1 구현 목표

- **접근 이원화** — 서버 URL 직접 접근(웹 SaaS) + PWA 로컬 설치 두 경로 모두 지원
- **Supabase 인증** — 이메일/소셜 로그인, 미가입 사용자는 기존 로컬 전용 사용 유지
- **로컬↔서버 DB 동기화** — 버전 기반 충돌 보호, 소프트 삭제, 충돌 해결 UI 포함
- **AI API 키 비동기화 보장** — `aiCredentials` 테이블은 동기화 대상에서 영구 제외

### 1.2 동기화 대상 스토어

| 스토어 | 동기화 | 비고 |
|--------|--------|------|
| journalStore (transactions) | ✅ | 핵심 |
| portfolioStore | ✅ | |
| watchlistStore | ✅ | |
| accountStore | ✅ | |
| cashFlowStore | ✅ | |
| dailyPnlStore | ✅ | |
| calendarStore (calendarEvents) | ✅ | |
| settingsStore | ❌ | 기기별 설정 — 제외 |
| aiCredentialStore | ❌ | **보안 — 절대 제외** |

### 1.3 구현 범위

**이번 구현 (Phase 12.02~12.07):** Supabase 인증 → DB 스키마 + 동기화 API → 동기화 엔진 → 설정 UI + 충돌 해결 → PWA 오프라인 개선 → 멀티디바이스 베타  
**제외 (후속):** Supabase Realtime 웹소켓 실시간 동기화, 팀/가족 공유 기능, Electron 패키징

```js
      },
```

#### Step 3 — authService.js 작성

**목표:** Supabase Auth 기능 래핑 (로그인·가입·로그아웃·세션 조회)  
**검증:** 각 함수 단독 호출 시 정상 응답

`src/services/authService.js` 신규 생성:
```js
// Supabase Auth 래퍼 서비스 (로그인/가입/로그아웃/세션)
import { supabase } from '@/lib/supabaseClient'

export const authService = {
  async signUpWithEmail(email, password) {
    if (!supabase) throw new Error('Supabase 미설정')
    const { data, error } = await supabase.auth.signUp({ email, password })
    if (error) throw error
    return data
  },

  async signInWithEmail(email, password) {
    if (!supabase) throw new Error('Supabase 미설정')
    const { data, error } = await supabase.auth.signInWithPassword({ email, password })
    if (error) throw error
    return data
  },

  async signInWithGoogle() {
    if (!supabase) throw new Error('Supabase 미설정')
    const { error } = await supabase.auth.signInWithOAuth({
      provider: 'google',
      options: { redirectTo: `${window.location.origin}/api/auth/callback` },
    })
    if (error) throw error
  },

  async signOut() {
    if (!supabase) return
    const { error } = await supabase.auth.signOut()
    if (error) throw error
  },

  async getSession() {
    if (!supabase) return null
    const { data: { session } } = await supabase.auth.getSession()
    return session
  },

  onAuthStateChange(callback) {
    if (!supabase) return { data: { subscription: { unsubscribe: () => {} } } }
    return supabase.auth.onAuthStateChange(callback)
  },
}
```

#### Step 4 — authStore.js Supabase 통합

**목표:** 기존 로컬 auth를 유지하면서 Supabase 계정 정보 추가  
**검증:** 로컬 모드 사용자 기존 기능 영향 없음, Supabase 로그인 시 `isSupabaseUser: true` 설정

`src/store/authStore.js` 수정 (기존 로컬 auth 구조 유지, Supabase 필드 추가):
```js
// 인증 상태 관리 — 로컬 auth 유지 + Supabase 계정 통합
import { create } from 'zustand'
import { persist } from 'zustand/middleware'
import { authService } from '@/services/authService'

export const useAuthStore = create(
  persist(
    (set, get) => ({
      // ── 기존 로컬 auth (변경 없음) ──
      currentUser: null,
      isLoggedIn: false,
      users: [],

      // ── Supabase 계정 (신규) ──
      isSupabaseUser: false,
      supabaseSession: null,

      // ── 기존 로컬 auth 액션 (변경 없음) ──
      login: (user) => set({ currentUser: user, isLoggedIn: true }),
      logout: async () => {
        if (get().isSupabaseUser) {
          await authService.signOut()
        }
        set({ currentUser: null, isLoggedIn: false, isSupabaseUser: false, supabaseSession: null })
      },

      // ── Supabase 세션 동기화 ──
      setSupabaseSession: (session) => {
        if (session) {
          set({
            isSupabaseUser: true,
            supabaseSession: session,
            isLoggedIn: true,
            currentUser: {
              id: session.user.id,
              email: session.user.email,
              name: session.user.user_metadata?.full_name || session.user.email,
            },
          })
        } else {
          set({ isSupabaseUser: false, supabaseSession: null })
        }
      },
    }),
    { name: 'auth-storage', version: 3 }
  )
)
```

#### Step 5 — App.jsx에 세션 리스너 등록

**목표:** 앱 시작 시 Supabase 세션 감지, 외부 탭 로그인/로그아웃 자동 반영  
**검증:** 다른 탭에서 로그아웃 시 현재 탭도 자동 로그아웃 처리

`src/App.jsx` 수정 (useEffect 추가):
```jsx
// App.jsx 상단 import 추가
import { authService } from '@/services/authService'
import { useAuthStore } from '@/store/authStore'

// App 컴포넌트 내부 useEffect 추가
useEffect(() => {
  // 앱 시작 시 기존 세션 복구
  authService.getSession().then((session) => {
    useAuthStore.getState().setSupabaseSession(session)
  })

  // 세션 변경 감지 (다른 탭 로그인/로그아웃 반영)
  const { data: { subscription } } = authService.onAuthStateChange((_event, session) => {
    useAuthStore.getState().setSupabaseSession(session)
  })

  return () => subscription.unsubscribe()
}, [])
```

#### Step 6 — SupabaseLoginModal.jsx 작성

**목표:** 이메일/Google 로그인·가입 모달 UI

`src/components/auth/SupabaseLoginModal.jsx` 신규 생성:
```jsx
// 서버 계정 로그인/가입 모달
import { useState } from 'react'
import { authService } from '@/services/authService'

export function SupabaseLoginModal({ onClose }) {
  const [mode, setMode] = useState('login') // 'login' | 'signup'
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [loading, setLoading] = useState(false)
  const [error, setError] = useState(null)

  const handleSubmit = async (e) => {
    e.preventDefault()
    setLoading(true)
    setError(null)
    try {
      if (mode === 'login') {
        await authService.signInWithEmail(email, password)
      } else {
        await authService.signUpWithEmail(email, password)
      }
      onClose()
    } catch (err) {
      setError(err.message)
    } finally {
      setLoading(false)
    }
  }

  return (
    <div className="fixed inset-0 bg-black/50 flex items-center justify-center z-50">
      <div className="bg-white dark:bg-gray-900 rounded-xl p-6 w-full max-w-md shadow-xl">
        <h2 className="text-xl font-bold mb-4">
          {mode === 'login' ? '서버 계정 로그인' : '서버 계정 만들기'}
        </h2>
        <form onSubmit={handleSubmit} className="space-y-4">
          <input
            type="email"
            placeholder="이메일"
            value={email}
            onChange={(e) => setEmail(e.target.value)}
            className="w-full border rounded-lg px-3 py-2"
            required
          />
          <input
            type="password"
            placeholder="비밀번호"
            value={password}
            onChange={(e) => setPassword(e.target.value)}
            className="w-full border rounded-lg px-3 py-2"
            required
          />
          {error && <p className="text-red-500 text-sm">{error}</p>}
          <button
            type="submit"
            disabled={loading}
            className="w-full bg-blue-600 text-white rounded-lg py-2 font-medium hover:bg-blue-700 disabled:opacity-50"
          >
            {loading ? '처리 중...' : mode === 'login' ? '로그인' : '가입하기'}
          </button>
        </form>
        <button
          onClick={() => authService.signInWithGoogle()}
          className="mt-3 w-full border rounded-lg py-2 hover:bg-gray-50"
        >
          Google로 계속하기
        </button>
        <button
          onClick={() => setMode(mode === 'login' ? 'signup' : 'login')}
          className="mt-4 text-sm text-blue-600 hover:underline w-full text-center"
        >
          {mode === 'login' ? '계정이 없으신가요? 가입하기' : '이미 계정이 있으신가요? 로그인'}
        </button>
        <button onClick={onClose} className="absolute top-4 right-4 text-gray-400 hover:text-gray-700">✕</button>
      </div>
    </div>
  )
}
```

#### Step 9 — db.js v11 마이그레이션 (로컬 IndexedDB)

**목표:** 로컬 Dexie 스키마에 sync 필드 추가

`src/utils/db.js` 수정 (version 11 추가):
```js
// v11 — 동기화 필드 추가 (syncVersion, syncedAt, deletedAt)
db.version(11).stores({
  transactions:   '&id, ticker, action, date, accountId, userId, syncVersion',
  cashFlows:      '&id, accountId, type, date, isAuto, userId, syncVersion',
  calendarEvents: '++id, userId, date, category, ticker, source, syncVersion',
  // 이하 v10과 동일한 테이블은 그대로 유지
  accounts:       '&id, userId',
  watchlist:      '&id, userId, ticker',
  holdings:       '&id, accountId, ticker, userId',
  priceHistory:   '[ticker+date], ticker, date',
  reports:        '&id, userId, type, period',
  alertHistory:   '++id, ticker, userId, createdAt',
  chatHistory:    '++id, userId, agentType, createdAt',
  aiCredentials:  '&provider',          // ← 동기화 제외 유지
  dailyPnl:       '[accountId+date], accountId, userId',
  stockMaster:    '&ticker, market, sector',
  sectorMaster:   '&code',
})
.upgrade(async (tx) => {
  // 기존 레코드에 syncVersion 기본값 설정
  await tx.transactions.toCollection().modify({ syncVersion: 0, syncedAt: null, deletedAt: null })
  await tx.cashFlows.toCollection().modify({ syncVersion: 0, syncedAt: null, deletedAt: null })
  await tx.calendarEvents.toCollection().modify({ syncVersion: 0, syncedAt: null, deletedAt: null })
})
```

syncVersion 증가 헬퍼 (db.js 파일 하단에 추가):
```js
// 레코드 저장 시 반드시 호출 — syncVersion 자동 증가
export function bumpSyncVersion(record) {
  return {
    ...record,
    syncVersion: (record.syncVersion ?? 0) + 1,
    syncedAt: null,   // null = 아직 서버에 동기화 안 됨
```

```js
// POST /api/sync/upload — 로컬 변경사항을 서버에 업로드
import { createClient } from '@supabase/supabase-js'

const supabase = createClient(
  process.env.VITE_SUPABASE_URL,
  process.env.SUPABASE_SERVICE_ROLE_KEY
)

// 테이블명 매핑 (로컬 Dexie → 서버 PostgreSQL)
const TABLE_MAP = {
  transactions:   'transactions',
  cashFlows:      'cash_flows',
  calendarEvents: 'calendar_events',
  accounts:       'accounts',
  watchlist:      'watchlist',
}

export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).end()

  const token = req.headers.authorization?.replace('Bearer ', '')
  const { data: { user }, error: authError } = await supabase.auth.getUser(token)
  if (authError || !user) return res.status(401).json({ error: 'Unauthorized' })

  const { records } = req.body  // [{ table, id, data, syncVersion, deletedAt }]

  const conflicts = []
  const upserted = []

  for (const record of records) {
    const pgTable = TABLE_MAP[record.table]
    if (!pgTable) continue

    // 서버 현재 버전 조회
    const { data: existing } = await supabase
      .from(pgTable)
      .select('id, sync_version')
      .eq('id', record.id)
      .single()

    if (existing && existing.sync_version > record.syncVersion) {
      // 충돌: 서버 버전이 더 높음
      conflicts.push({ id: record.id, table: record.table, serverVersion: existing.sync_version, localVersion: record.syncVersion })
      continue
    }

    await supabase.from(pgTable).upsert({
      id:           record.id,
      user_id:      user.id,
      data:         record.data,
      sync_version: record.syncVersion,
      synced_at:    new Date().toISOString(),
      deleted_at:   record.deletedAt ?? null,
    })
    upserted.push(record.id)
  }

  // 글로벌 버전 업데이트
  await supabase.from('user_sync_meta').upsert({
    user_id:        user.id,
    global_version: Date.now(),
    last_synced_at: new Date().toISOString(),
  })

  res.status(200).json({ upserted, conflicts })
}
```

`src/services/syncService.js` 신규 생성:
```js
// 로컬↔서버 동기화 엔진 — 업로드/다운로드/충돌 감지
import { db } from '@/utils/db'
import { supabase } from '@/lib/supabaseClient'
import { useSyncStore } from '@/store/syncStore'

// 동기화 대상 테이블 목록 (aiCredentials 제외)
const SYNC_TABLES = ['transactions', 'cashFlows', 'calendarEvents', 'accounts', 'watchlist']

async function getAuthToken() {
  const { data: { session } } = await supabase.auth.getSession()
  return session?.access_token
}

export const syncService = {
  // 서버 버전 확인
  async checkServerVersion() {
    const token = await getAuthToken()
    if (!token) return null
    const res = await fetch('/api/sync/version', {
      headers: { Authorization: `Bearer ${token}` },
    })
    if (!res.ok) return null
    return res.json()
  },

  // 미동기화 변경사항 서버로 업로드
  async uploadPending() {
    const store = useSyncStore.getState()
    store.setSyncStatus('syncing')

    try {
      const token = await getAuthToken()
      if (!token) throw new Error('로그인 필요')

      const pending = []
      for (const table of SYNC_TABLES) {
        const records = await db[table]
          .filter((r) => !r.syncedAt || r.syncVersion > 0)
          .toArray()
        records.forEach((r) => pending.push({ table, id: r.id, data: r, syncVersion: r.syncVersion ?? 1, deletedAt: r.deletedAt ?? null }))
      }

      if (pending.length === 0) {
        store.setSyncStatus('synced')
        return { conflicts: [] }
      }

      const res = await fetch('/api/sync/upload', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json', Authorization: `Bearer ${token}` },
        body: JSON.stringify({ records: pending }),
      })
      const result = await res.json()

      // 충돌 처리
      if (result.conflicts?.length > 0) {
        result.conflicts.forEach((c) => store.addConflict(c))
      }

      // 성공한 레코드의 syncedAt 업데이트
      for (const id of result.upserted ?? []) {
        for (const table of SYNC_TABLES) {
          await db[table].where('id').equals(id).modify({ syncedAt: new Date().toISOString() }).catch(() => {})
        }
      }

      store.setLastSyncedAt(new Date().toISOString())
      store.resetPending()
      store.setSyncStatus(result.conflicts?.length > 0 ? 'conflict' : 'synced')
      return result
    } catch (err) {
      store.setSyncStatus('error')
      throw err
    }
  },

  // 서버에서 로컬로 다운로드
  async downloadFromServer(since = null) {
    const store = useSyncStore.getState()
    store.setSyncStatus('syncing')

    try {
      const token = await getAuthToken()
      if (!token) throw new Error('로그인 필요')

      const url = since ? `/api/sync/download?since=${since}` : '/api/sync/download'
      const res = await fetch(url, { headers: { Authorization: `Bearer ${token}` } })
      const serverData = await res.json()

      // 로컬 Dexie에 병합 (버전 높은 쪽 우선)
      const tableMap = {
        transactions: 'transactions',
        cash_flows:   'cashFlows',
        calendar_events: 'calendarEvents',
        accounts:     'accounts',
        watchlist:    'watchlist',
      }

      for (const [pgTable, localTable] of Object.entries(tableMap)) {
        const rows = serverData[pgTable] ?? []
        for (const row of rows) {
          const existing = await db[localTable].get(row.id)
          if (!existing || existing.syncVersion <= row.sync_version) {
            if (row.deleted_at) {
              await db[localTable].delete(row.id).catch(() => {})
            } else {
              await db[localTable].put({ ...row.data, id: row.id, syncVersion: row.sync_version, syncedAt: row.synced_at })
            }
          }
        }
      }

      store.setLastSyncedAt(new Date().toISOString())
      store.setSyncStatus('synced')
    } catch (err) {
      store.setSyncStatus('error')
      throw err
    }
  },

  // 최초 로그인 시 로컬 전체 데이터 서버로 마이그레이션
  async migrateLocalToServer() {
    for (const table of SYNC_TABLES) {
      const records = await db[table].toArray()
      for (const r of records) {
        await db[table].put({ ...r, syncVersion: 1, syncedAt: null })
      }
    }
    return this.uploadPending()
  },
}
```

```js
// 동기화 상태 훅 — 컴포넌트에서 상태 읽기 및 트리거용
import { useEffect, useCallback } from 'react'
import { useSyncStore } from '@/store/syncStore'
import { useAuthStore } from '@/store/authStore'
import { syncService } from '@/services/syncService'

export function useSyncStatus() {
  const { syncStatus, pendingChanges, lastSyncedAt, autoSync, syncEnabled } = useSyncStore()
  const { isSupabaseUser } = useAuthStore()

  const triggerSync = useCallback(async () => {
    if (!isSupabaseUser || !syncEnabled) return
    await syncService.uploadPending()
  }, [isSupabaseUser, syncEnabled])

  // 온라인 복구 시 자동 동기화
  useEffect(() => {
    if (!autoSync || !isSupabaseUser) return

    const handleOnline = () => {
      if (pendingChanges > 0) triggerSync()
    }
    window.addEventListener('online', handleOnline)
    return () => window.removeEventListener('online', handleOnline)
  }, [autoSync, isSupabaseUser, pendingChanges, triggerSync])

  return {
    syncStatus,
    pendingChanges,
    lastSyncedAt,
    triggerSync,
    isSyncing: syncStatus === 'syncing',
    hasConflict: syncStatus === 'conflict',
    isOnline: navigator.onLine,
  }
}
```

**목표:** 최초 Supabase 로그인 시 기존 로컬 데이터를 서버로 이전하는 모달

`src/components/auth/MigrateDataModal.jsx` 신규 생성:
```jsx
// 최초 서버 로그인 시 로컬 데이터 이전 모달
import { useState } from 'react'
import { syncService } from '@/services/syncService'

export function MigrateDataModal({ onClose }) {
  const [status, setStatus] = useState('idle') // 'idle' | 'migrating' | 'done' | 'error'
  const [error, setError] = useState(null)

  const handleMigrate = async () => {
    setStatus('migrating')
    try {
      await syncService.migrateLocalToServer()
      setStatus('done')
    } catch (err) {
      setError(err.message)
      setStatus('error')
    }
  }

  return (
    <div className="fixed inset-0 bg-black/50 flex items-center justify-center z-50">
      <div className="bg-white dark:bg-gray-900 rounded-xl p-6 w-full max-w-md shadow-xl">
        <h2 className="text-xl font-bold mb-2">기존 데이터 서버로 이전</h2>
        <p className="text-sm text-gray-500 mb-4">
          로컬에 저장된 매매일지, 포트폴리오, 관심종목 등의 데이터를 서버로 업로드합니다.
          AI API 키는 보안상 이전되지 않습니다.
        </p>

        {status === 'done' && (
          <p className="text-green-600 font-medium mb-4">✅ 이전 완료! 이제 멀티디바이스로 사용할 수 있습니다.</p>
        )}
        {status === 'error' && (
          <p className="text-red-500 text-sm mb-4">{error}</p>
        )}

        {status !== 'done' && (
          <button
            onClick={handleMigrate}
            disabled={status === 'migrating'}
            className="w-full bg-blue-600 text-white rounded-lg py-2 font-medium hover:bg-blue-700 disabled:opacity-50 mb-3"
          >
            {status === 'migrating' ? '이전 중...' : '서버로 이전하기'}
          </button>
        )}

        <button
          onClick={onClose}
          className="w-full border rounded-lg py-2 text-sm hover:bg-gray-50"
        >
          {status === 'done' ? '닫기' : '나중에 하기'}
        </button>
      </div>
    </div>
  )
}
```

#### Step 20 — 자동 동기화 인터벌 설정

```jsx
// 동기화 인터벌 설정
useEffect(() => {
  const { autoSync, syncInterval } = useSyncStore.getState()
  const { isSupabaseUser } = useAuthStore.getState()
  if (!autoSync || !isSupabaseUser || syncInterval === 'manual' || syncInterval === 'realtime') return

  const intervalMs = syncInterval === '15m' ? 15 * 60 * 1000 : 60 * 60 * 1000
  const timer = setInterval(() => {
    syncService.uploadPending()
  }, intervalMs)

  return () => clearInterval(timer)
}, [])
```

## 6. 의존성 및 설치 순서

```
묶음 A → 묶음 B → 묶음 C → 묶음 D → 묶음 E
(Supabase 연결 없이 B 불가, syncService 없이 D 불가)
```

묶음 A와 B는 순서 필수. 묶음 C, D는 병렬 가능(서로 독립). 묶음 E는 C, D 완료 후 진행.

## 7. 보안 불변 원칙

이 구현 전 과정에서 반드시 지켜야 할 원칙.

1. **AI API 키 비동기화** — `aiCredentials` 테이블은 `SYNC_TABLES` 목록에서 영구 제외. 코드 리뷰 시 재확인 필수.
2. **Service Role Key 격리** — `SUPABASE_SERVICE_ROLE_KEY`는 `api/` 서버리스 함수에서만 사용. `src/` 클라이언트 코드에 절대 노출 금지.
3. **RLS 활성화 확인** — 모든 Supabase 테이블에 `enable row level security` 필수. 신규 테이블 추가 시 즉시 적용.
4. **VITE_ 접두사 주의** — `VITE_SUPABASE_ANON_KEY`는 Anon Key(공개 가능)만 사용. Service Role Key는 절대 `VITE_` 접두사로 노출하지 않는다.
