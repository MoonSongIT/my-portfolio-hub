# 10.07 관심종목(Watchlist) 기능 개선 계획

> 작성일: 2026-05-15  
> 담당: dohay  
> 상태: 검토 중

---

## 1. 배경 및 목적

현재 관심종목 페이지는 실시간 가격 조회, 가격 알림(이상/이하), 카드·테이블 뷰 전환, AI 브리핑 등 기본 기능을 갖추고 있다. 그러나 네이버 금융·TradingView·키움증권 HTS·Yahoo Finance 등 주요 서비스 대비 아래 영역이 부족하다.

- **그룹 관리 없음** — 모든 종목이 단일 플랫 리스트
- **목표가 추적 없음** — 메모 필드(자유 텍스트)만 있어 구조화 불가
- **알림 이력 없음** — 발동 후 토스트만 표시, 히스토리 유실
- **추가일 기준 성과 없음** — `addedAt` 필드는 있으나 수익률 미계산
- **재정렬 불가** — 순서 고정, 드래그앤드롭 미지원

## 3. 개선 항목 및 우선순위

### Priority 1 — 즉각 체감 효과 (이번 스프린트 핵심)

#### 3.1 그룹(폴더) 관리
**Why:** 10개 이상 종목을 관리하면 단일 리스트가 혼잡해진다. 네이버·TradingView·키움 모두 지원하는 기본 기능이다.

**구현 범위:**
- 그룹 CRUD (생성·이름변경·삭제)
- 기본 그룹 "전체" + 사용자 정의 그룹 (최대 10개)
- 종목을 복수 그룹에 할당 가능 (태그 방식)
- 그룹 탭 UI — 상단 탭으로 전환
- `watchlistStore`에 `groups: []` 필드 추가

**데이터 구조 변경:**
```js
// groups 배열 추가
groups: [
  { id: 'g1', name: '성장주', color: '#6366f1', createdAt: '2026-05-15T09:00:00.000Z' },
  { id: 'g2', name: '배당주', color: '#10b981', createdAt: '2026-05-15T09:00:00.000Z' },
]

// 종목 item에 groupIds 추가
watchlist: [
  { ticker: '005930', name: '삼성전자', ..., groupIds: ['g1'] }
]
```

---

#### 3.2 목표가·손절가 트래킹
**Why:** "언제 팔아야 하나"를 구조화해 관리하고 달성률을 시각화하면 의사결정에 직접 도움이 된다.

**구현 범위:**
- 종목별 필드: `targetPrice` (목표가), `stopLoss` (손절가), `entryPrice` (참고 매입가)
- 카드·테이블 뷰에서 달성률 프로그레스 바 표시
- 목표가 대비 현재 거리(%) 표시
- 알림 설정과 연동: 목표가 입력 시 "목표가 알림 자동 생성" 옵션 제공

**UI 스케치:**
```
삼성전자        ↑+2.5%
현재가 75,000
목표가 80,000  [=========>  ] 94%  남은 거리 +6.7%
손절가 68,000  안전 ✅
```

**데이터 구조 변경:**
```js
// watchlist item에 필드 추가
{
  ticker: '005930',
  entryPrice: 72000,     // 참고 매입가 (수동 입력)
  targetPrice: 80000,    // 목표가
  stopLoss: 68000,       // 손절가
  priceAtAdded: 72000,   // 추가 당시 가격 (자동 스냅샷)
}
```

---

### Priority 2 — 알림 고도화

#### 3.3 알림 이력(Alert History)
**Why:** 알림이 발동됐을 때 토스트만 뜨고 사라지면 못 본 경우 히스토리 유실. 트리거 이력을 남겨야 패턴 분석에 활용 가능.

**구현 범위:**
- `alertHistory: []` 배열을 store에 추가
- 알림 발동 시 이력 append
- 알림 이력 드로어(Drawer) UI — 우상단 벨 아이콘 클릭 시 오픈
- 이력 최대 100건 유지 (오래된 것 자동 삭제)
- 읽음/안 읽음 표시

**데이터 구조:**
```js
alertHistory: [
  {
    id: 'ah-uuid',
    ticker: '005930',
    name: '삼성전자',
    condition: 'above',      // 'above' | 'below'
    targetPrice: 75000,
    actualPrice: 75200,
    firedAt: '2026-05-15T10:30:00.000Z',
    read: false
  }
]
```

---

#### 3.4 알림 일시정지·재개
**Why:** 장기 보유 중 단기 변동에 알림이 계속 뜨면 노이즈. 일시정지 기능이 필요하다.

**구현 범위:**
- 알림별 `paused: boolean` 필드 추가
- `AlarmDialog`에 토글 스위치 제공
- 일시정지 상태 알림은 체크 건너뜀 + 배지 회색 표시

---

### Priority 3 — 성과 분석

#### 3.5 추가일 기준 수익률
**Why:** `addedAt` 필드가 이미 있고, 추가 당시 `priceAtAdded`를 스냅샷하면 수익률 계산 가능. 관심종목에서 얼마나 움직였는지 한눈에 파악.

**구현 범위:**
- 종목 추가 시 `priceAtAdded` 자동 저장
- 카드 뷰에 "추가 후 수익률" 배지 표시 (예: `since +12.3%`)
- 테이블 뷰에 "추가후 변동" 컬럼 추가 (선택 표시)
- 기존 종목은 `priceAtAdded` 없으면 표시 생략

---

#### 3.6 섹터 분포 미니차트
**Why:** 종목 item에 `sector` 필드가 이미 있다. 간단한 파이차트로 업종 쏠림 파악 가능.

**구현 범위:**
- 관심종목 상단에 접을 수 있는 섹터 분포 파이차트 (Recharts 재사용)
- 섹터별 종목 수 + 비중 표시
- 단일 섹터 편중 시 경고 배지

---

### Priority 4 — 편의기능

#### 3.7 드래그앤드롭 재정렬
**Why:** 중요한 종목을 상단에 직접 배치하고 싶은 수요. 현재는 기준값 정렬만 가능.

**구현 범위:**
- `@dnd-kit/core` + `@dnd-kit/sortable` 사용 (인기 종목에서 이미 사용 중)
- 카드·테이블 뷰 모두 지원
- `watchlist` 배열 순서를 store에 반영 (localStorage 영속)
- 정렬 기준 선택 중에는 DnD 비활성화

---

#### 3.8 CSV 내보내기
**Why:** 엑셀에서 추가 분석하거나 다른 앱으로 마이그레이션할 때 필요.

**구현 범위:**
- 우상단 "내보내기" 버튼
- CSV 컬럼: 티커, 종목명, 시장, 현재가, 추가일, 메모, 목표가, 손절가
- 브라우저 Blob 다운로드 (서버 불필요)

## 4. 구현 단계 (권장 순서)

```
Phase A (Sprint 10.7.1) — 그룹 관리 + 목표가 트래킹
  1. watchlistStore — groups, entryPrice, targetPrice, stopLoss, priceAtAdded 필드 추가 + persist v6 마이그레이션
  2. 그룹 탭 UI (GroupManager 컴포넌트)
  3. 목표가 달성률 프로그레스 바 (TargetPriceBar 컴포넌트)

Phase B (Sprint 10.7.2) — 알림 고도화
  4. alertHistory 스토어 추가
  5. 알림 이력 드로어 (AlertHistoryDrawer 컴포넌트)
  6. 알림 일시정지 토글 (AlarmDialog 수정)

Phase C (Sprint 10.7.3) — 성과 분석 + 편의기능
  7. priceAtAdded 스냅샷 + 수익률 배지
  8. 섹터 분포 미니차트
  9. 드래그앤드롭 재정렬
  10. CSV 내보내기
```

## 7. 미결정 사항 (사용자 확인 필요)

1. **그룹 방식** — 단일 폴더(1종목 = 1그룹) vs 복수 태그(1종목 = 여러 그룹) 중 어떤 게 더 편한지.
2. **이번 스프린트 범위** — Phase A만 할지, A+B를 한 번에 할지.
3. **목표가 알림 자동 생성** — 목표가 입력 시 알림을 자동으로 만들지, 수동으로만 할지.
4. **뉴스 피드** — 외부 뉴스 API 연동이 필요해 별도 스프린트로 분리할지.
