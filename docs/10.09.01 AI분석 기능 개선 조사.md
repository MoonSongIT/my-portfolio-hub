## 1. 현재 AI 분석 기능 현황

### 1.1 에이전트 구조 (src/agents/)

| 에이전트 | 파일 | 현재 기능 | 한계 |
|---------|------|----------|------|
| ResearchAgent | researchAgent.js | 종목 기본 분석 (시세·재무·기술적 지표·뉴스 5건) | 뉴스를 나열만 하고 가격 움직임과 연계 해석 없음 |
| AlertAgent | alertAgent.js | 관심종목 등락률 기준 알림 | "왜 움직였는가" 설명 없이 수치만 전달 |
| Orchestrator | orchestrator.js | 키워드 기반 에이전트 라우팅 | "왜 폭락했나" 의도 감지 불가 |
| JournalCoachAgent | journalCoachAgent.js | 매매 심리 분석·코칭 | AI 분석과 연결 없음 |
| ReportAgent | reportAgent.js | 기간 성과 리포트 | 시장 맥락 설명 없음 |

### 1.2 API 레이어 (src/api/)

| 파일 | 역할 | 현재 상태 |
|------|------|---------|
| newsApi.js | Yahoo + Naver 뉴스 수집 | 종목당 최대 5건, 제목+날짜+링크만 수집 |
| disclosureApi.js | DART 공시 수집 | 제목·날짜만, 내용 파싱 없음 |
| technicalApi.js | MA·RSI·MACD 계산 | 수치만 제공, AI 해석 없음 |
| stockApi.js | 시세 조회 | 가격 데이터만, 등락 이유 없음 |

### 1.3 현재 AI 분석 진입점

```
사용자가 직접 채팅창에 질문 → ChatPanel → claudeApi
종목 상세 페이지 → AI 분석 버튼 → ResearchAgent
종목 탐색 → AI 스크리너 → SCREENER_PROMPT
```

### 1.4 핵심 부재 기능 (Gap Analysis)

1. **급등락 원인 자동 해석 없음** — 종목이 ±5% 이상 움직여도 뉴스·공시와 연계한 AI 설명이 없음.
2. **시장 전반 브리핑 없음** — 오늘 KOSPI/NASDAQ이 왜 하락하는지 AI가 요약해주는 화면 없음.
3. **뉴스 센티먼트 미분석** — 뉴스를 목록으로 나열만 하고 긍·부정 영향 해석이 없음.
4. **프로액티브(Proactive) 인사이트 없음** — 사용자가 먼저 물어봐야만 분석이 시작됨.
5. **업종 연동 분석 없음** — "삼성전자 하락 → 반도체 섹터 전반 영향" 같은 연쇄 분석 없음.
6. **라우팅 미흡** — "왜 폭락", "이유가 뭐야" 같은 원인 질문이 portfolio로 오라우팅됨.

## 2. 글로벌 벤치마킹

### 2.1 Robinhood Cortex (Gold 구독, $5/월)

**핵심 기능: Cortex Digests**

> "AI를 활용해 보유 종목/관심 종목의 가격이 움직이는 이유를 breaking news·애널리스트 보고서·시장 데이터를 종합해 Plain-language로 요약 제공"

| 특징 | 내용 |
|------|------|
| 트리거 방식 | 종목이 크게 움직일 때 자동 생성 (Push 방식) |
| 분석 소스 | 실시간 시장 데이터 + 애널리스트 보고서 + 뉴스 |
| 포트폴리오 Digest | 보유 전체 자산에 대한 통합 AI 설명 |
| 출력 | 간결한 3~5문장 한국어 요약 |
| 시사점 | **"왜 움직였나"를 사용자가 묻기 전에 먼저 제공** |

### 2.2 Seeking Alpha — Virtual Analyst Reports

## 3. 사용자 니즈 분석

### 3.1 명시적 요구사항 (사용자 직접 언급)

1. **"특정 종목이 폭락·폭등하는데 그 이유를 찾아서 해석해주는 기능"**
   - 종목 상세에서 가격 급변 시 AI가 뉴스·공시 기반으로 원인 설명
   - 사용자가 직접 물어보지 않아도 자동으로 표시

2. **"전체 주가가 출렁이는 이유를 최근 뉴스를 분석해주는 기능"**
   - 시장 지수(KOSPI·KOSDAQ·S&P500·NASDAQ) 움직임 설명
   - 매크로 이슈(금리·환율·지정학)와 연결

### 3.2 암묵적 니즈

- 채팅보다 **빠른 진입** — 버튼 하나로 "왜 움직였는가" 확인
- **내 보유종목 중심** — 관심 없는 종목 아닌 내 포트폴리오 관련 설명
- **한국어 + 한국 뉴스 소스** — 국내 종목은 네이버 금융·DART 기반

## 4. 기술적 실현 가능성 검토

### 4.1 현재 인프라로 가능한 것

| 기능 | 현재 인프라 | 추가 필요 |
|------|------------|---------|
| 뉴스 기반 원인 분석 | newsApi.js 있음 | Claude에 뉴스+가격 함께 전달하는 로직 |
| 공시 기반 해석 | disclosureApi.js 있음 | 공시 내용 파싱 + Claude 연동 |
| 시장 지수 브리핑 | stockApi.js로 지수 조회 가능 | 지수 변동 + 글로벌 뉴스 묶어서 분석 |
| 급등락 트리거 | 없음 | 가격 모니터링 + 임계값 감지 로직 |
| 센티먼트 스코어 | 없음 | Claude에게 긍/부정 판단 요청 |

### 4.2 신규 개발 필요 영역

1. **PriceMovementExplainer** — 등락률 + 뉴스 + 공시를 묶어 Claude에 전달하는 컨텍스트 빌더
2. **MarketBriefAgent** — 시장 지수 + 글로벌 뉴스 기반 시장 전반 브리핑 에이전트
3. **MovementExplainer UI** — 종목 상세 페이지에 "오늘의 이유" 섹션 추가
4. **DailyMarketBrief UI** — 대시보드 또는 종목탐색 페이지에 시장 브리핑 섹션
5. **Orchestrator 개선** — "왜", "이유", "폭락", "급등" 키워드 → analysis 에이전트로 라우팅
