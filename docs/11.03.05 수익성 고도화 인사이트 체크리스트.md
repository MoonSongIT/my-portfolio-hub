## 📋 개요

이 문서는 Phase 11.03.04 "수익성 고도화 인사이트" 구현 과정에서 필요한 검증 작업을 단계별로 정의합니다.

**핵심 목표**:
- 거래 저장 후 3초 이내 AI 기반 역사 피드백 표시
- 3회 이상 반복 손실 패턴 자동 감지 및 경고
- 심리별 수익률 순위 차트가 Reports 페이지에 표시
- 종목×심리 2D 매트릭스로 교차 분석 가능

**체크리스트 진행 방식**:
1. 각 작업 항목 앞의 `[ ]` 체크박스에 완료 시 `[x]` 표시
2. 검증 방법(Verification) 항목 우측에 실제 실행 결과 기록
3. 모든 항목이 ✅ 완료될 때까지 단계 완료로 간주하지 않음
