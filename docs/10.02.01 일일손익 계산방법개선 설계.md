# 10.02.01 일일손익 계산방법 개선 설계

## 개요

대시보드 '오늘 손익' KPI를 **아침대비 손익**과 **오늘 실현손익**으로 세분화한다.

---

## 배경 및 문제점

### 현재 구현 (Dashboard.jsx L127-153)

```
① 당일 스냅샷 존재 → snapshots.dailyPnl 합산
② 스냅샷 없는 종목 → (currentPrice - previousClose) × quantity (API fallback)
③ calcDailyChange(prevTotal, totalValue) → { amount, rate }
```

**문제점:**
- 보유종목 미실현 손익(시가 대비)과 당일 매도 실현손익이 혼재
- 스냅샷 저장 타이밍에 따라 값이 달라지는 불안정성
- 매도 후 "오늘 얼마 벌었나"를 별도로 파악할 수 없음

---

## 개선 목표

| KPI 카드 | 의미 | 계산 방식 |
|---------|------|---------|
| **아침대비 손익** | 전일종가 대비 보유종목 미실현 손익 | 실시간 (API) |
| **오늘 실현손익** | 당일 매도 거래 실현손익 합계 | 매도 entry 기반 |

## 계산 공식

### 아침대비 손익 (미실현, 실시간)

```
아침대비손익 = Σ (currentPrice - previousClose) × quantity × 환율보정
```

- 데이터 소스: `batchData` (r.data.currentPrice, r.data.previousClose)
- 갱신 시점: batchData 업데이트마다 (화면 갱신 시)
- USD 종목: × exchangeRate 적용
- **스냅샷 불필요**

### 오늘 실현손익 (매도 기반)

```
오늘실현손익 = Σ entry.pnl  (action==='sell' AND date===today)
```

- 데이터 소스: `journalStore.entries`
- `entry.pnl`은 매도 시 자동 계산되어 저장됨 (journalStore.js L54-64)
  - 공식: `(매도가 - 평균단가) × 수량 - 수수료`
- USD 매도 entry.pnl은 원화폐 단위로 저장 → 환율 재적용 불필요

## 구현 계획

### Step 1: `src/utils/calculator.js` — 함수 추가

```javascript
// 아침대비 손익
export const calcMorningComparePnl = (holdings, batchData, exchangeRate = 1300) => {
  if (!batchData) return { amount: 0, rate: 0 }
  let pnl = 0
  let prevTotal = 0
  batchData.forEach(r => {
    if (!r.success || !r.data?.previousClose) return
    const { currentPrice, previousClose } = r.data
    holdings
      .filter(h => h.ticker === r.ticker)
      .forEach(h => {
        const rate = h.currency === 'USD' ? exchangeRate : 1
        pnl += (currentPrice - previousClose) * h.quantity * rate
        prevTotal += previousClose * h.quantity * rate
      })
  })
  return {
    amount: Math.round(pnl),
    rate: prevTotal > 0 ? (pnl / prevTotal) * 100 : 0,
  }
}

// 오늘 실현손익
export const calcRealizedTodayPnl = (entries, today) => {
  const todaySells = entries.filter(e => e.action === 'sell' && e.date === today)
  const amount = todaySells.reduce((sum, e) => sum + (e.pnl ?? 0), 0)
  return { amount: Math.round(amount), count: todaySells.length }
}
```

### Step 2: `src/pages/Dashboard.jsx` — memo 분리

기존 `dailyChange` memo 대체:

```javascript
// 아침대비 손익 (미실현, 실시간)
const morningPnl = useMemo(() => {
  return calcMorningComparePnl(holdings, batchData, exchangeRate)
}, [holdings, batchData, exchangeRate])

// 오늘 실현손익 (매도 기반)
const realizedTodayPnl = useMemo(() => {
  const today = new Date().toISOString().split('T')[0]
  return calcRealizedTodayPnl(entries, today)
}, [entries])
```
