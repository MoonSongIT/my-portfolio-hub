## 수동 테스트 시나리오

### 시나리오 A — Finnhub 자동 탐색
1. Settings → Finnhub API 키 입력 후 저장
2. 증시 일정 → [자동 탐색] → 이번 달 → Finnhub 선택
3. FetchPreviewModal 열림 + 미국 실적/IPO 이벤트 목록 표시 확인
4. 일부 체크박스 해제 후 [선택 저장]
5. 월간 캘린더에서 저장된 이벤트 source='finnhub' 배지 확인

### 시나리오 B — DART 자동 탐색
1. Settings → DART API 키 확인 (기존 저장된 키)
2. 증시 일정 → [자동 탐색] → 이번 달 → DART 선택
3. FetchPreviewModal에 국내 배당/실적 공시 이벤트 표시 확인
4. [선택 저장] → 캘린더 갱신 확인

### 시나리오 C — 매매일지 연계
1. 종목(ticker) 있는 이벤트 클릭 → EventDetailModal 열림
2. [일지 작성] 버튼 표시 확인 (ticker 없는 이벤트에서는 숨김)
3. 클릭 → Journal 페이지로 이동 + 날짜·종목 사전 입력 확인

### 시나리오 D — 임팩트 필터
1. 이벤트 여러 개 추가 (high/medium/low 각 1개씩)
2. 임팩트 필터 [높음 ★★★] 클릭 → high 이벤트만 표시
3. 월간 뷰에서 high 이벤트에 ★★★ 표시 확인

### 시나리오 E — 브라우저 알림
1. Settings → 알림 켜기 → 권한 허용
2. 알림 시점: 당일 09:00, 임팩트: 높음 설정
3. 오늘 날짜에 impact:'high' 이벤트 등록
4. 증시 일정 페이지 진입 → Console에서 스케줄 등록 로그 확인
