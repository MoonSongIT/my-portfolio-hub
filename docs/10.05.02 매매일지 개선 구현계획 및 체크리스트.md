## Sprint 10.5.2 — 날짜 범위 필터 + HTS Import UI

### B. 날짜 범위 필터

#### 설계 결정 — B-5 통계 연동 방식 (방향 A)

스토어 함수에 `baseEntries?` 선택 파라미터 추가. 미전달 시 `get().entries` 사용 — 하위 호환 유지.

```
Journal.jsx
 ├─ dateRange state (기본값: 'all')
 ├─ filteredEntries = useMemo(() => filterByDateRange(entries, dateRange), [...])
 ├─ chartData = getProfitByPsychology(accountFilter, exchangeRate, filteredEntries)
 ├─ stats = getSummaryStats(accountFilter, filteredEntries)
 └─ <JournalList dateRange={dateRange} ... />
         └─ 내부 filter 체인에 날짜 조건 추가
```

**왜 방향 A인가.**
- `getProfitByPsychology`는 USD→KRW 환산 포함 비교적 복잡한 로직 → 중복 금지
- 파라미터 옵셔널이므로 기존 호출부 전부 무수정
- 순수 유틸 분리(방향 C)는 집계 함수가 늘어날 때 리팩터링

- 차트: Recharts BarChart (`CashFlowChart.jsx` 패턴 참고)
- 위치: 요약 통계 카드 아래, 심리별 차트 위

#### 작업 목록

> 파일: `src/pages/Journal.jsx` (수정)

- [x] **E-1.** 월별 집계 useMemo 추가 (최근 6개월)
  ```js
  const monthlyStats = useMemo(() => {
    const map = {}
    filteredEntries.forEach(e => {
      const month = e.date?.slice(0, 7)
      if (!month) return
      if (!map[month]) map[month] = { month, 거래건수: 0, 실현손익: 0 }
      map[month].거래건수 += 1
      if (e.pnl != null) map[month].실현손익 += e.pnl
    })
    return Object.values(map).sort((a, b) => a.month.localeCompare(b.month)).slice(-6)
  }, [filteredEntries])
  ```
- [x] **E-2.** 월별 트렌드 BarChart Card 추가 (거래건수 + 실현손익 이중 막대)
