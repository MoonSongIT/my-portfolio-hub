### [FEAT-01] 대시보드 수익률 추이 차트 — 투자원금+손익 누적 막대 오버레이

**관련 파일**
- `src/components/charts/ProfitLineChart.jsx`

**배경**

대시보드 수익률 추이(AreaChart)는 누적 수익률 %만 보여준다.
실제 자산 규모(투자원금 + 누적 손익)가 어떻게 쌓여 왔는지는 한눈에 안 들어온다.

> 참고: 1차 구현에서 "일간 증감치(%p) 막대"로 오버레이했으나, 의도는 금액 기준 누적 막대였음. 본 항목은 누적 스택 막대로 재구현한 결과를 반영한다. 포트폴리오 꺾은선(HoldingPnlTimeline)은 적용 범위에서 제외(원복).

**목표**

대시보드 차트 한 화면에서 "수익률 흐름(누적 %) + 자산 규모(투자원금+손익 누적 금액)"를 함께 읽을 수 있게 한다.

**선택 차트 조합 — ComposedChart : Area + 스택 Bar + 이중 Y축**

| 레이어 | 데이터 | Y축 | 색상 |
|--------|--------|-----|------|
| Area (기존 유지) | `returnRate` 누적 수익률 % | 좌측 | 그린/레드 그라디언트 |
| Bar 하단 (신규) | `principalBase` = min(투자원금, 평가액) | 우측(금액) | 회색 (#cbd5e1) |
| Bar 상단 (신규) | `pnlSegment` = \|평가액−투자원금\| | 우측(금액) | 이익=#EF4444(빨강), 손실=#3B82F6(파랑) |
| ReferenceLine y=0 | 기준선 | 좌측 | 회색 점선 |

막대 해석:
- 손익 양수 → 베이스=투자원금(회색) + 위에 이익(빨강), 막대 전체 = 총 평가액
- 손익 음수 → 베이스=평가액(회색) + 위에 손실(파랑), 막대 전체 = 투자원금

선택 이유:
- `investedValue`(투자원금), `totalValue`(평가액) 필드가 데이터에 이미 존재 → 컴포넌트 내 파생만으로 계산
- 스택 막대가 "원금 위에 손익이 쌓이는" 누적 구조를 직관적으로 표현
- 이중 Y축으로 수익률(%)과 금액(원) 스케일 충돌 방지
- 한국 색상 컨벤션(이익=빨강, 손실=파랑) 적용

**구현 범위**

1. `ProfitLineChart.jsx`
   - 우측 `YAxis`를 금액 축(`formatCurrencyShort`, domain=[0, max])으로 변경
   - `dailyReturn` 단일 막대 → `principalBase` + `pnlSegment` 스택 막대(stackId)로 교체
   - 손익 부호로 상단 세그먼트 Cell 색상 분기
   - Tooltip: 누적 수익률 / 투자원금 / 손익합계 / 총 평가액 표시

2. `HoldingPnlTimeline.jsx`
   - 1차 구현분(일간 증감 Bar) 원복 — 적용 범위에서 제외

### [FIX-01] 자금 입출금 수정 모달 — 선택 정보 미표시·수정 불가

**관련 파일**
- `src/components/portfolio/CashFlowModal.jsx`

**증상**

자금관리에서 입출금 항목의 "수정" 버튼을 눌러도 팝업에 선택한 정보(금액·카테고리·날짜·메모)가 채워지지 않고 빈 폼이 뜬다.

**원인**

- 호출부(`CashFlowHistory.jsx`)는 `editTarget`(선택 항목)을 모달에 전달하지만, `CashFlowModal`이 `editTarget` prop을 받지 않아 무시됨.
- 모달의 init `useEffect`가 열릴 때 전 필드를 빈값으로 초기화.
- 저장 시 `addCashFlow`만 호출 → 수정이 아니라 새 항목으로 중복 추가됨.
- 스토어에는 `updateCashFlow(id, updates)`가 이미 존재했으나 모달이 호출하지 않음.

**수정**

1. `CashFlowModal`에 `editTarget` prop 추가 → 있으면 해당 값으로 폼 초기화(type·계좌·카테고리·금액·통화·날짜·메모)
2. 제출 시 `editTarget`이면 `updateCashFlow(id, payload)`, 아니면 기존 `addCashFlow(payload)`
3. 입금↔출금 탭 전환 시 카테고리 초기화를 `useEffect([type])` → 탭 클릭 핸들러(`handleTypeChange`)로 이동 (수정 모드 첫 로드에서 카테고리가 지워지는 문제 방지)
4. 헤더 제목/저장 버튼 라벨을 수정 모드일 때 "입출금 수정 / 수정 저장"으로 표시
