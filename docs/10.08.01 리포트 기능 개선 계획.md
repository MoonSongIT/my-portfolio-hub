## 1. 배경 및 목적

### 현재 상태 진단

현재 리포트 페이지는 기본 골격은 갖추어졌으나 개인 투자 성장 도구로서의 **심층 인사이트**가 부족하다.

| 현재 구현 | 수준 |
|-----------|------|
| KPI 카드 4종 (수익률·벤치마크·거래횟수·승률) | ✅ 기본 |
| 성과추이 벤치마크 라인 차트 | ✅ 기본 |
| TOP/BOTTOM 종목 순위 | ✅ 기본 |
| 실현/미실현 손익 비교 | ✅ 기본 |
| 거래내역 테이블 | ✅ 기본 |
| AI 주간·월간 리포트 생성 | ✅ 기본 |
| 배당 현황 | ✅ 기본 |
| 날짜 범위: 1d / 1w / 1m / 1y 고정 | ⚠️ 제한적 |
| 심리 유형별 수익 패턴 분석 | ❌ 없음 |
| 리스크 지표 (MDD·변동성) | ❌ 없음 |
| 거래 패턴 분석 (요일·업종별) | ❌ 없음 |
| 목표 달성률 추적 | ❌ 없음 |
| 과거 AI 리포트 열람 UI | ❌ 없음 |
| 수익/손실 히트맵 캘린더 | ❌ 없음 |

### 벤치마킹 조사 요약

#### Sharesight (글로벌 1위 포트폴리오 트래커)
- **Multi-period Report**: 최대 5개 기간 동시 비교
- **TWR 기반** 정확한 성과 측정 (자본 입출금 왜곡 제거)
- **3분리 분석**: 자본이득 / 배당 / 환율 영향 각각 표시
- **다차원 분류**: 국가·업종·시장·통화별 성과 드릴다운
- 세금 리포트 (양도소득, 배당소득 자동 계산)
- PDF/Excel/Google Sheets 내보내기

#### Tradervue / Edgewonk (트레이딩 저널 특화)
- **매매 심리·행동 패턴** 심층 분석 (강점/약점 자동 탐지)
- **요일별·시간대별·업종별 수익률** 히트맵
- AI 기반 패턴 감지 및 개선 제안 (TraderSync는 이미 도입)
- 연속 수익/손실 스트릭 표시

#### 도미노 / 증권플러스 (국내 포트폴리오 앱)
- 초단위 실시간 포트폴리오 가치 변화 그래프
- 여러 증권사 통합 뷰 + 기간별 자산 변화 추이

### 개선 방향

이 앱의 핵심 목적인 **"매매 심리 기록 → AI 피드백 → 투자 성장"** 에 집중하여 아래 세 축으로 개선한다.

1. **심리 분석 심화** — journalStore의 psychology 데이터를 시각화로 확장
2. **리스크/성과 정량화** — MDD·변동성 등 투자자가 체감할 수 있는 지표 추가
3. **AI 리포트 UX 개선** — 히스토리 조회, 자동 트리거, 커스텀 기간 선택

## 2. 개선 항목 (우선순위별)

### 🔴 P1 — 핵심 (반드시)

#### 2-1. 심리 패턴 분석 탭 신설
**위치:** 현재 6탭 → 7탭 (기존 탭 순서 유지, 맨 뒤에 추가)

**내용:**

| 섹션 | 차트 유형 | 데이터 |
|------|-----------|--------|
| 심리 유형별 평균 손익 | 수평 BarChart | `entries` groupBy psychology → 평균 pnl |
| 심리 유형별 승률 | RadialBarChart 또는 BarChart | 수익거래수 / 전체거래수 |
| 반복 실수 패턴 카드 | 텍스트 카드 | 동일 심리 3회 이상 손실 → 경고 |
| 잘된 결정 강화 카드 | 텍스트 카드 | 수익률 상위 30% 거래의 공통 심리 |

**활용 기존 코드:**
- `src/components/charts/PsychologyProfitChart.jsx` — 재활용 가능
- `src/utils/calculator.js#calculateWinRate` — 재활용 가능
- `src/store/journalStore.js` — `entries[].psychology` 필드

**신규 컴포넌트:** `src/components/reports/PsychologyAnalysis.jsx`

#### 2-2. 커스텀 기간 선택 (날짜 피커)

**현재:** 4개 고정 버튼만 존재  
**개선:** "직접 설정" 버튼 추가 → shadcn/ui Popover + Calendar로 DateRangePicker 구현

```jsx
// Reports.jsx 상태 확장 예시
const [customRange, setCustomRange] = useState({ from: null, to: null })
// dateRange가 'custom'이면 customRange.from ~ customRange.to로 필터링
```

**필요 패키지:** `shadcn/ui Popover`, `Calendar` — 이미 설치됨 (신규 설치 불필요)

#### 2-3. AI 리포트 히스토리 뷰

**현재:** 주간 리포트 저장 버튼만 있고 과거 리포트 조회 UI 없음  
**개선:**

**신규 컴포넌트:** `src/components/reports/ReportHistoryDrawer.jsx`

### 🟡 P2 — 중요 (가능하면)

#### 2-4. 리스크 지표 KPI 카드 추가
**현재 KPI 4종 → 6종으로 확장 (2개 추가)**

| 추가 KPI | 설명 | 계산 방법 |
|----------|------|-----------|
| 최대낙폭 (MDD) | 기간 내 고점 대비 최대 손실률 | `dailyPnlStore` 스냅샷으로 누적 수익률 시계열 → peak-to-trough |
| 포트폴리오 변동성 | 일간 수익률 표준편차 (연환산) | `σ(일간 수익률) × √252` |

**활용 기존 코드:** `src/store/dailyPnlStore.js` — `snapshots` 필드  
**추가 필요:** `src/utils/calculator.js`에 `calculateMDD()`, `calculateVolatility()` 함수  
**신규 컴포넌트:** `src/components/reports/RiskKpiCards.jsx` (또는 기존 KPICard 재활용)

#### 2-5. 수익/손실 히트맵 캘린더
**위치:** 심리분석 탭 상단 또는 성과추이 탭 하단

**내용:** 월 캘린더 형태로 날짜별 손익 표시
- 수익 날짜: 빨강 (한국 색상 컨벤션 — 상승=빨강)
- 손실 날짜: 파랑 (하락=파랑)
- 색상 강도: 손익 절댓값에 비례

**데이터 소스:** `journalStore.entries` → 날짜별 실현손익 집계  
**구현 방법:** CSS Grid 기반 커스텀 컴포넌트 (recharts 불필요)  
**신규 컴포넌트:** `src/components/reports/PnlHeatmapCalendar.jsx`

#### 2-6. 거래 패턴 분석 (요일·업종별)

## 5. 검증 방법

1. **심리 분석 탭**: 거래 일지에 다양한 심리 유형 데이터 입력 → 바차트·승률 차트 정상 렌더링
2. **날짜 피커**: 임의 기간 선택 → KPI·차트·테이블 모두 해당 기간 데이터 필터링 확인
3. **AI 리포트 히스토리**: 리포트 생성 후 목록에 나타나는지, 클릭 시 내용 조회 가능한지 확인
4. **MDD 계산**: dailyPnlStore 스냅샷 충분 시 수동 계산값과 비교 검증
5. **히트맵 컬러**: 수익 날짜 빨강 / 손실 날짜 파랑 (한국 색상 컨벤션)
6. **커스텀 기간**: 기존 1d/1w/1m/1y 버튼 동작 영향 없는지 회귀 테스트
