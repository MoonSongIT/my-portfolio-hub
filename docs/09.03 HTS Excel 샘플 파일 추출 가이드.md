## 개요

HTS에서 거래내역을 Excel로 내보내는 방법은 크게 세 가지이다.

| 방법 | 화면 | 데이터 내용 | 권장 용도 |
|------|------|------------|-----------|
| **A. 체결내역 조회** | 계좌 → 체결내역 | 매수/매도 체결 건별 상세 | import 핵심 데이터 ✅ |
| B. 실현손익 조회 | 계좌 → 실현손익 | 매도 완료 건 손익 합산 | 수익률 검증 참고 |
| C. 잔고 조회 | 계좌 → 잔고 | 현재 보유 종목/수량 | 보유종목 재계산 참고 |

> Sprint 9.1 파싱 테스트를 위한 **최우선 확보 대상: 방법 A (체결내역)**

---

## 방법 A — 체결내역 조회 Excel 추출

### A-1. HTS 실행 및 로그인

1. 유진투자증권 챔피언 HTS 실행
2. 공동인증서 또는 ID/PW 로그인

### A-2. 체결내역 화면 열기

다음 중 한 가지 방법으로 접근:

```
① 상단 메뉴: [계좌] → [주문체결] → [체결내역 조회]
② 단축번호: HTS 좌측 검색창에 화면번호 입력
   - 일반적으로 "0312" 또는 "0301" (버전별 상이)
③ 화면 검색: 우측 상단 검색 아이콘 → "체결내역" 입력
```

### A-3. 조회 조건 설정

| 항목 | 권장값 | 비고 |
|------|--------|------|
| 조회기간 | 최근 1~3개월 | 일 단위 설정 가능 |
| 계좌 | 본인 계좌 선택 | 복수 계좌 시 각각 추출 |
| 종목 | 전체 | 특정 종목만 필터 가능 |
| 구분 | 전체 (매수+매도) | |

### A-4. 조회 실행

- **[조회]** 버튼 클릭
- 화면 하단 그리드에 체결 건 목록 표시 확인

### A-5. Excel 저장

```
방법 1 (권장): 그리드 우클릭 → [Excel 저장] 또는 [엑셀로 저장]
방법 2: 화면 상단 툴바의 엑셀 아이콘 클릭
방법 3: 키보드 단축키 Ctrl+E (HTS 버전별 상이)
```

- 저장 형식: `.xlsx` 또는 `.xls` → **`.xlsx` 권장**
- 저장 경로: 바탕화면 또는 지정 폴더

## 샘플 파일 제공 전 마스킹 처리

개인정보 보호를 위해 공유 전 아래 항목을 마스킹한다.

| 항목 | 마스킹 방법 | 예시 |
|------|------------|------|
| 계좌번호 | 중간 자리 `*` 처리 | `30-****-1234` |
| 주민번호 | 열 전체 삭제 | — |
| 이름 | 성씨만 남기고 `*` | `김**` |
| 주문번호 | 유지 (중복방지 키로 사용) | `20260401001` |
| 종목코드/명 | 유지 (공개 정보) | `005930 삼성전자` |

### Excel에서 마스킹하는 방법

1. Excel 파일 열기
2. 해당 열 선택 → `Ctrl+H` (찾기/바꾸기)로 치환
3. 또는 해당 셀 직접 클릭 → 값 수정

### Mock Excel 직접 생성 방법

**방법 1 — Google Sheets 사용 (가장 간단)**

1. [Google Sheets](https://sheets.google.com) 에서 새 스프레드시트 생성
2. 위 데이터를 A1 셀부터 붙여넣기
3. 파일 → 다운로드 → Microsoft Excel (.xlsx)

**방법 2 — 로컬 Node 스크립트**

```bash
# xlsx 패키지 설치 (전역)
npm install -g xlsx
```

```js
// scripts/createMockHts.js
import * as XLSX from 'xlsx'

const rows = [
  ['거래일자','종목코드','종목명','매매구분','체결수량','체결단가','수수료','제세금','주문번호'],
  ['20260401','005930','삼성전자','매수',10,72000,1080,0,'20260401001'],
  ['20260410','000660','SK하이닉스','매수',5,185000,925,0,'20260410001'],
  ['20260415','005930','삼성전자','매도',5,75000,375,1125,'20260415001'],
  ['20260420','035720','카카오','매수',20,48000,960,0,'20260420001'],
]

const ws = XLSX.utils.aoa_to_sheet(rows)
const wb = XLSX.utils.book_new()
XLSX.utils.book_append_sheet(wb, ws, '체결내역')
XLSX.writeFile(wb, 'mock_hts_sample.xlsx')
console.log('mock_hts_sample.xlsx 생성 완료')
```

```bash
node scripts/createMockHts.js
```
