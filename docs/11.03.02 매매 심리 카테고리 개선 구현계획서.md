## 1. 개요

### 1.1 현황 분석
- **기존 구조**: BUY_PSYCHOLOGY(8개), SELL_PSYCHOLOGY(7개) 평탄 배열
- **문제점**:
  - 심리 카테고리 선택 시 시각적 구분 부족 (버튼 나열식)
  - 카테고리 의미 불명확 (직관성 낮음)
  - 카테고리 확장 불가능 (하드코딩된 문자열 배열)
  - 사용자 피드백/히스토리 추적 불가
- **범위**: `PsychologySelector.jsx`, `journalStore.js`, 분석 리포트 유지
- **제약조건**: 기존 데이터 완벽 호환성 유지 (`psychology: string`)

### 1.2 개선 목표
1. **구조화된 선택 UX**: 그룹별 정렬, 이모지 지시자, 설명 텍스트
2. **확장 가능한 메타데이터**: 카테고리 추가/수정/삭제 가능
3. **사용 이력 피드백**: 자주 선택한 카테고리, 최근 선택, 성과 연동
4. **데이터 일관성**: 기존 거래 데이터 완벽 호환

## 2. 설계 안

### 2.1 최종 심리 카테고리 (12 매수 + 11 매도)

#### 매수 심리 (12개)

| 그룹 | 이모지 | 카테고리 | 설명 |
|------|--------|----------|------|
| **기본전략** | 📈 | 미래가치 투자 | 기업 가치와 미래 성장성을 중심으로 매수 |
| **기본전략** | 📈 | 분할매수 원칙 | 목표 가격 아래에서 계획된 물량을 단계적으로 매수 |
| **기본전략** | 📈 | 저가 매수 | 저평가된 종목을 찾아 매수 |
| **추세전략** | 🚀 | 기술적 분석(상승추세) | 이동평균선 등 기술 지표가 상승 신호를 보일 때 매수 |
| **추세전략** | 🚀 | 추격매매(모멘텀) | 급등하는 종목의 추진력을 따라 매수 |
| **뉴스/이벤트** | 📰 | 뉴스 편승 | 긍정적 뉴스, 호재에 반응하여 매수 |
| **뉴스/이벤트** | 📰 | 목표가 도달 | 투자자들의 목표가 달성으로 기대감 상승 시 매수 |
| **리밸런싱** | ⚖️ | 리밸런싱 | 포트폴리오 비중 조정 목적의 매수 |
| **심리적요인** | 😌 | FOMO(두려움) | 다른 투자자들의 수익을 본 후 따라 매수 |
| **심리적요인** | 😌 | 되돌림 매수(손절후) | 손절 후 다시 올라오자 되돌림 매수 |
| **패턴** | 🔄 | 외국인/기관 추종 | 외국인·기관의 매수 흐름을 따라 매수 |
| **기타** | ❓ | 기타 | 상기 어느에도 해당하지 않는 경우 |

#### 매도 심리 (11개)

| 그룹 | 이모지 | 카테고리 | 설명 |
|------|--------|----------|------|
| **수익실현** | ✅ | 목표가 실현 | 설정한 수익 목표에 도달하여 매도 |
| **수익실현** | ✅ | 수익 실현(조급) | 충동적으로 작은 이익에 서둘러 매도 |
| **수익실현** | ✅ | 리밸런싱 | 포트폴리오 비중 조정 목적의 매도 |
| **손절** | 🛑 | 손절 원칙 | 손실 한도를 미리 정하고 실행한 손절 |
| **손절** | 🛑 | 공포에 매도 | 급락 시 공포심에 후다닥 매도 |
| **손절** | 🛑 | 되돌림 손절(수익후) | 일부 수익 후 급락하여 손절 |
| **기술적매도** | 📉 | 기술적 분석(하락추세) | 이동평균선 등 기술 지표가 하락 신호를 보일 때 매도 |
| **심리적요인** | 😌 | 과신에서의 손절 | 과신했던 종목이 예상과 달라 매도 |
| **뉴스/이벤트** | 📰 | 악재 반응 | 부정적 뉴스, 악재에 반응하여 매도 |
| **패턴** | 🔄 | 외국인/기관 이탈 | 외국인·기관의 매도 흐름을 따라 매도 |

```javascript
// src/utils/psychologyHelper.js (신규 파일)
import { PSYCHOLOGY_METADATA, PSYCHOLOGY_MIGRATION_MAP } from '../store/journalStore'

export const getGroupedPsychology = (action) => {
  const metadata = PSYCHOLOGY_METADATA[action];
  return Object.entries(metadata).map(([groupKey, groupData]) => ({
    groupKey,
    groupName: groupKey,
    emoji: groupData.emoji,
    color: groupData.color,
    description: groupData.description,
    categories: groupData.categories,
  }));
};

export const getPsychologyInfo = (action, value) => {
  const metadata = PSYCHOLOGY_METADATA[action];
  for (const group of Object.values(metadata)) {
    const cat = group.categories.find(c => c.value === value);
    if (cat) return { ...cat, emoji: group.emoji, color: group.color };
  }
  return null;
};

export const migratePsychologyValue = (action, value) => {
  const map = PSYCHOLOGY_MIGRATION_MAP[action];
  return map?.[value] || value;
};
```

**UI 레이아웃**:

```
┌─ 그룹 헤더 (이모지 + 이름) ─┐
│ 📈 기본전략                    │
├──────────────────────────┤
│ [미래가치투자] [분할매수원칙] │
│  기업가치중심   단계별매수   │
└──────────────────────────┘
```

**컴포넌트 코드**:

```jsx
import { getGroupedPsychology, getPsychologyInfo } from '../../utils/psychologyHelper'

export default function PsychologySelector({ action, value, onChange }) {
  const groups = getGroupedPsychology(action)

  return (
    <div className="space-y-4">
      {groups.map((group) => (
        <div key={group.groupKey} className="border rounded-lg p-4 bg-gray-50 dark:bg-gray-800">
          <h3 className="text-sm font-semibold text-gray-700 dark:text-gray-200 mb-3 flex items-center gap-2">
            <span className="text-lg">{group.emoji}</span>
            {group.groupName}
          </h3>

          <div className="grid grid-cols-1 md:grid-cols-2 gap-2">
            {group.categories.map((cat) => (
              <button
                key={cat.value}
                type="button"
                onClick={() => onChange(cat.value)}
                className={`p-3 rounded-lg border-2 transition-all text-left ${
                  value === cat.value
                    ? 'border-blue-600 bg-blue-50 dark:bg-blue-900'
                    : 'border-gray-300 dark:border-gray-600 hover:border-blue-400'
                }`}
              >
                <div className="font-medium text-sm text-gray-800 dark:text-gray-100">
                  {cat.label}
                </div>
                <div className="text-xs text-gray-500 dark:text-gray-400 mt-1">
                  {cat.hint}
                </div>
              </button>
            ))}
          </div>
        </div>
      ))}
    </div>
  )
}
```
