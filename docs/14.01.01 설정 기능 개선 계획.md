## 2. 문제점 식별

### 2.1 제거 대상: 불필요하거나 잘못된 기능

#### 문제 A — settingsStore 미노출 필드
- `settingsStore.js`에 `language`, `currency`, `annualTargetReturn` 필드가 정의되어 있으나 Settings 화면에 UI가 없음
- 쓰이지 않는 상태이므로 store 정리 대상

#### 문제 B — 버전 하드코딩
- 앱 정보 섹션에 버전이 `"1.1.0 (Phase 11)"`로 하드코딩됨
- 실제 package.json 버전은 `0.1.0`이라 불일치 상태
- `"Phase 11"`은 개발 내부 용어로 일반 사용자에게 노출 부적절

#### 문제 C — 종목 DB의 "원본 직접 수집" 모드
- `preferredSource === 'origin'` 시 전체/증분/국내/해외 업데이트 버튼 4개 노출
- "개발 서버 실행 중에만 업데이트 가능합니다 (API 프록시 경유)" 경고가 붙어 있어 일반 사용자는 사용 불가
- 일반 사용자 화면에서 해당 버튼들은 사실상 비기능적 UI

### 2.2 개선 대상: 부정확하거나 혼란스러운 UI

#### 문제 D — AI 키 패널 3중 반복
- AiKeyPanel, DartKeyPanel, FinnhubKeyPanel이 99% 동일한 구조
- 각각 내부에 삭제 확인 모달을 보유 (코드 중복 3배)
- "이 키는 본인 브라우저(IndexedDB)에만 저장됩니다" 보안 안내가 3회 반복
- 사용자는 3개 카드를 개별적으로 스크롤하며 관리해야 함

#### 문제 E — 서버 계정 + 동기화 섹션 분리
- 동기화는 Supabase 로그인이 전제 조건이지만, 두 섹션이 분리되어 있음
- 미로그인 시 동기화 섹션이 "Supabase 계정으로 로그인하면 동기화 설정을 사용할 수 있습니다" 텍스트만 표시 — 섹션이 눈에 보이는 채로 비어있는 것처럼 보임

#### 문제 F — 증시 일정 알림 UX
- 알림이 비활성 상태일 때 "알림 시점"과 "중요도 필터" 셀렉트가 `disabled` + `opacity-40` 처리됨
- opacity만으로 비활성화를 표현하면 시각적으로 충분히 구분되지 않음
- "브라우저가 닫혀 있으면 발송되지 않습니다" 제한 안내가 회색 소자 텍스트 수준으로 표시 — 알림의 핵심 한계임에도 눈에 잘 안 띔

#### 문제 G — 데이터 관리 vs 데이터 정리 분리
- "데이터 관리" (9번)와 "데이터 정리" (10번)가 별도 섹션으로 분리
- 사용자 시각에서 둘 다 "내 데이터를 관리하는" 같은 맥락 — 한 섹션으로 합칠 수 있음

#### 문제 H — 관심종목 기본값 이탈 경고
- 입력값 변경 후 저장 버튼을 누르지 않고 페이지를 벗어나면 변경 무효화
- "저장하지 않으면 변경사항이 사라집니다" 텍스트 경고가 있지만 이탈 방지 장치 없음

### 2.3 복잡도 단순화 대상

#### 문제 I — 종목 DB 관리의 과도한 복잡도
현재 StockMasterPanel 기능 목록:
- 데이터 출처 선택 (원본 직접 수집 / 서버에서 받기)
- 전체 업데이트, 증분 동기화, 국내 업데이트, 해외 업데이트 (4개 버튼)
- 서버 다운로드 버튼
- 관리자 전용 서버 업로드 버튼
- 국내/해외 거래소 카드 그리드 (접기/펼치기)
- 커스텀 종목 추가 폼

일반 사용자에게 필요한 것은 "서버에서 받기" + 현황 확인뿐.

#### 문제 J — Confirm 모달 난립
Settings 화면에 독립적으로 존재하는 confirm 모달 5개:
1. 백업 복원 확인 (Settings.jsx)
2. 전체 초기화 확인 (Settings.jsx)
3. Anthropic API 키 삭제 확인 (AiKeyPanel.jsx)
4. DART API 키 삭제 확인 (DartKeyPanel.jsx)
5. Finnhub API 키 삭제 확인 (FinnhubKeyPanel.jsx)

## 3. 개선 방향

### 3.1 섹션 재구성 (11개 → 6개)

| 새 섹션 | 포함 항목 | 변경 내용 |
|--------|---------|---------|
| **앱 설정** | 테마, 벤치마크, 관심종목 기본값 | 관심종목 기본값을 이곳으로 통합 |
| **알림** | 브라우저 알림, 알림 시점, 중요도 필터 | 비활성화 시 하위 옵션 conditional hide |
| **API 키** | Anthropic, DART, Finnhub 키 통합 | 3개 패널 → 단일 통합 패널 (테이블 형태) |
| **연결 & 동기화** | 서버 계정 + 동기화 | 미로그인 시 동기화 옵션 숨김, 로그인 후 펼침 |
| **종목 DB** | 서버 다운로드 중심으로 단순화 | 일반 사용자: 다운로드 버튼 + 현황만 표시 |
| **데이터** | 백업&복원, HTS 가져오기, 저장소 현황, 전체 초기화, 앱 정보 | 데이터 관리+정리 통합 + 앱 정보 포함 |

관리자 섹션(UserRoleManager)은 조건부로 독립 유지.

### 3.2 API 키 통합 패널 구조

```
[AI 및 API 키 관리]
┌───────────────┬────────────┬──────────────────┬────────────┐
│ 서비스         │ 상태       │ 용도             │ 액션       │
├───────────────┼────────────┼──────────────────┼────────────┤
│ Anthropic AI  │ ✓ 검증완료  │ AI 채팅 기능     │ 변경 / 삭제│
│ DART          │ ✓ 저장됨   │ 국내 공시 조회    │ 변경 / 삭제│
│ Finnhub       │ 미설정      │ 미국 실적·IPO    │ 설정       │
└───────────────┴────────────┴──────────────────┴────────────┘
[보안 안내: 한 번만 표시]
```

- 개별 입력 폼은 "변경/설정" 버튼 클릭 시 인라인 확장 (accordion 방식)
- 삭제 확인은 공용 ConfirmModal 하나로

### 3.3 종목 DB 단순화 방향

**일반 사용자 화면:**
```
[종목 데이터베이스]
총 X,XXX개 · 마지막 업데이트: N월 N일
[서버에서 받기 버튼]
```

**관리자 전용 영역 (isAdmin && isSupabaseUser):**
- 원본 직접 수집 버튼 (전체/증분/국내/해외)
- 서버로 업로드 버튼
- 거래소 카드 그리드

커스텀 종목 폼은 그대로 유지.

### 3.4 버전 표기 개선

Settings.jsx에서 package.json에서 버전을 읽어오도록 수정 (`import.meta.env.VITE_APP_VERSION` 또는 `vite.config.js`의 `define` 활용).
`"Phase 11"` 텍스트는 제거.

### 3.5 증시 알림 UX 개선

- 알림 비활성 상태: 알림 시점 / 중요도 필터 영역 전체를 숨김 (conditional render)
- 핵심 한계 문구 ("브라우저가 닫혀 있으면 발송되지 않습니다")를 노란색 경고 박스로 격상

### 3.6 관심종목 기본값 — 즉시 저장으로 전환

- 현재: draft 상태 관리 + 별도 저장 버튼
- 개선: 각 input의 `onBlur` 시 즉시 store 저장 (onChange가 아닌 onBlur → 타이핑 중 중간 상태 저장 방지)
- 미저장 배지, 경고 텍스트, 저장 버튼 제거 → UI 단순화
