### Step 2 — 데이터 레이어

**목표:** IndexedDB 테이블 정의, Zustand 스토어 생성  
**검증:** 이벤트 저장/조회/삭제 정상 동작

#### 2-1. db.js 캘린더 테이블 추가

기존 Dexie DB 버전에 `calendarEvents` 테이블만 추가 (기존 테이블 수정 없음).

**이벤트 스키마:**

| 필드 | 타입 | 설명 |
|------|------|------|
| id | 자동 증가 | PK |
| userId | string | 사용자 격리 |
| date | 'YYYY-MM-DD' | 이벤트 날짜 |
| endDate | 'YYYY-MM-DD' \| null | 기간 이벤트 종료일 |
| title | string | 이벤트 제목 |
| category | string | 'earnings' \| 'dividend' \| 'ipo' \| 'economic' \| 'custom' |
| ticker | string \| null | 연관 종목 티커 |
| market | string \| null | 'KRX' \| 'NYSE' \| 'NASDAQ' |
| impact | string | 'high' \| 'medium' \| 'low' |
| source | string | 'manual' \| 'dart' \| 'finnhub' \| 'krx' |
| memo | string | 메모 |
| createdAt | ISO 문자열 | 생성 시각 |

#### 2-2. calendarDb.js 헬퍼 함수

```js
getEventsByMonth(userId, year, month)    // 특정 월 이벤트
getEventsByYear(userId, year)             // 특정 연도 전체 (히트맵용)
getEventsByRange(userId, startDate, endDate) // 날짜 범위
addEvent(userId, eventData)
updateEvent(id, eventData)
deleteEvent(id)
```

#### 2-3. calendarStore.js 상태 구조

```js
{
  events: [],            // 현재 뷰의 이벤트 목록
  view: 'month',         // 'year' | 'month' | 'week'
  currentDate: Date,     // 현재 표시 기준 날짜
  filterCategory: 'all', // 'all' | 'earnings' | 'dividend' | 'ipo' | 'economic' | 'custom'
  filterScope: 'all',    // 'all' | 'watchlist' | 'portfolio'
}
```

## 6. 구현 시 주의사항

1. **Dexie 버전 관리** — 기존 테이블 수정 없이 `calendarEvents`만 신규 추가. 버전 번호 +1.
2. **FullCalendar CSS 충돌** — `@fullcalendar/core/main.css` import 위치를 Tailwind 이후로. 필요 시 `.fc-*` 클래스 오버라이드.
3. **사용자 격리** — 모든 DB 쿼리에 `userId` 필터 필수 (기존 journal/cashflow 패턴 준수).
4. **source 필드** — 수동 추가 이벤트는 `source: 'manual'` 고정. 향후 API 이벤트와 구분.
5. **연간 뷰 성능** — 365개 셀 렌더링 시 `useMemo`로 이벤트 밀도 맵 사전 계산.
6. **모바일 반응형** — FullCalendar 월간 뷰의 모바일 최소 행 높이, 헤더 버튼 크기 조정.

## 8. 단계적 구현 묶음

"단계 완료 시 실제로 동작하는 것이 있는가"를 기준으로 4개 묶음으로 구분한다.

```
묶음 A  →  묶음 B  →  묶음 C  →  묶음 D
기반 설정     핵심 MVP     뷰 확장       완성
(확인 가능)  (쓸 수 있음)  (3뷰 완성)   (완전 완성)
~50분        ~120분        ~90분         ~80분
```

### 묶음 A — 기반 설정 (Step 1 + Step 2)

**완료 시 상태:** 메뉴가 사이드바에 나타나고, DB 구조와 스토어가 준비됨

| Step | 작업 | 난이도 | 예상 시간 |
|------|------|--------|---------|
| 1 | Sidebar + App.jsx 메뉴/라우트 추가 | 낮음 | 10분 |
| 2 | db.js 테이블 + calendarDb.js + calendarStore.js | 낮음 | 40분 |

> 커밋: `feat: 증시 일정 메뉴 진입점 + 데이터 레이어`

### 묶음 B — 핵심 MVP (Step 3 + Step 6)

**완료 시 상태:** 이벤트를 추가하고 월간 달력으로 볼 수 있는 최소 기능

| Step | 작업 | 난이도 | 예상 시간 |
|------|------|--------|---------|
| 3 | FullCalendar 설치 + CalendarMonthView | 중간 | 60분 |
