## Sprint 10.4.3 — calculator.js 수익률 분모 개선

> 파일: `src/utils/calculator.js` (수정)

### 10.4.3-A. calculateNetCapital 함수 추가

- [ ] `calculateNetCapital(cashFlows)` 함수 추가
  ```js
  // cashFlows 배열에서 isCapital=true 항목만 필터하여 순 투자원금 계산
  export const calculateNetCapital = (cashFlows) => {
    const capitalFlows = cashFlows.filter(f => {
      if (f.isAuto) return false
      const cat = Object.values(CASH_FLOW_CATEGORIES).find(c => c.code === f.category)
      return cat?.isCapital === true
    })
    const krw = capitalFlows
      .filter(f => f.currency !== 'USD')
      .reduce((sum, f) => sum + (f.type === 'deposit' ? f.amount : -f.amount), 0)
    const usd = capitalFlows
      .filter(f => f.currency === 'USD')
      .reduce((sum, f) => sum + (f.type === 'deposit' ? f.amount : -f.amount), 0)
    return { krw, usd }
  }
  ```
- [ ] `CASH_FLOW_CATEGORIES` import 추가 (`../store/cashFlowStore`)

### 10.4.3-B. 수익률 계산 함수에 순 투자원금 적용

- [ ] 기존 수익률 계산이 사용되는 곳 파악 (Dashboard, Portfolio, Reports 등)
- [ ] 관련 계산 함수에서 분모를 `calculateNetCapital` 결과로 교체
  ```js
  // 개선된 수익률 분모
  const netCapital = calculateNetCapital(cashFlows)
  const capitalKRW = netCapital.krw + (netCapital.usd * exchangeRate)
  const returnRate = capitalKRW > 0
    ? (totalValue - capitalKRW) / capitalKRW * 100
    : 0
  ```
- [ ] `capitalKRW === 0`(투자금 미입력) 케이스 — 0% 또는 "—" 표시로 처리
